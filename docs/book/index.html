Building AI Voice Studio

A Complete Python & wxPython Guide
From Zero to Desktop Application

This book teaches you every concept of Python — basic, intermediate, and advanced — through the lens of a real-world desktop application: AI Voice Studio, a text-to-speech studio built with wxPython, sherpa-onnx, and NumPy.

By the time you finish, you will be able to build, test, and package a complete Python desktop application on your own.

First Edition • 2026 • Python 3.13 • wxPython 4.3
Based on AI Voice Studio (AIVS) open-source project

Preface

Who This Book Is For

This book is designed for programmers who want to learn Python from the ground up and apply their knowledge to build a real, functional desktop application. Whether you are a complete beginner, an intermediate developer expanding your skills, or an experienced programmer new to Python, this book provides a structured path from fundamentals to advanced topics.

How This Book Is Organized

The book is divided into nine parts:

  1. Part I — Python Fundamentals (Chapters 1–10): Variables, control flow, functions, file I/O, error handling, modules, and object-oriented basics.
  2. Part II — Intermediate Python (Chapters 11–18): Advanced OOP, decorators, context managers, regular expressions, testing, and structured data.
  3. Part III — Advanced Python (Chapters 19–26): Concurrency, multiprocessing, async I/O, type hints, metaclasses, design patterns, and introspection.
  4. Part IV — wxPython GUI Development (Chapters 27–36): Building desktop interfaces, event handling, threading in GUI apps, accessibility, and theming.
  5. Part V — Dependencies Deep Dive (Chapters 37–42): NumPy, Requests, sherpa-onnx, PDF/DOCX parsing, FFmpeg, and virtual environments.
  6. Part VI — Building AI Voice Studio (Chapters 43–60): The complete project from architecture to every major subsystem.
  7. Part VII — Testing & Deployment (Chapters 61–66): Unit testing, mocking, PyInstaller, Inno Setup, and CI/CD.
  8. Part VIII — Advanced Topics (Chapters 67–72): Managed runtime, subprocess architecture, logging, performance, and security.
  9. Part IX — Second Edition Additions (Chapters 73–75): Playlist generation, DAISY 3 book building, and reusable dialogs and progress windows.

The Running Example: AI Voice Studio

Rather than teaching concepts in isolation, every chapter applies what it teaches to AI Voice Studio (AIVS) — a production-quality desktop application that converts text documents into spoken audio using neural TTS engines. The project demonstrates:

  • wxPython GUI with accessibility support (NVDA, JAWS, Narrator)
  • Multiple TTS engines (Piper, Kokoro, Matcha, Kitten, XTTS v2 cloning)
  • Document parsing (PDF, DOCX, HTML, Markdown, EPUB)
  • Background threading for non-blocking synthesis
  • Virtual environment management and addon architecture
  • PyInstaller packaging and Inno Setup installers
  • 99+ unit tests with comprehensive coverage

Prerequisites

  • A computer running Windows (primary), macOS, or Linux
  • Python 3.11 or later installed
  • A text editor or IDE (VS Code, PyCharm, or similar)
  • No prior Python experience required — we start from scratch
