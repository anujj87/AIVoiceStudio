9.1 Import Basics

9.2 Creating Modules

Any .py file is a module. If you create mymodule.py:

# mymodule.py
"""My custom module for audio utilities."""

SAMPLE_RATE = 24000

def format_duration(seconds: float) -> str:
    """Format seconds as HH:MM:SS."""
    h = int(seconds // 3600)
    m = int((seconds % 3600) // 60)
    s = int(seconds % 60)
    return f"{h:02d}:{m:02d}:{s:02d}"

9.3 Creating Packages

├── __init__.py            # Makes it a package (can be empty)
├── paths.py               # Module: ai_voice_studio.paths
├── settings.py            # Module: ai_voice_studio.settings
├── tts/                   # Sub-package
│   ├── __init__.py
│   ├── catalog.py         # Module: ai_voice_studio.tts.catalog
│   ├── engine.py
│   └── models.py
├── gui/                   # Sub-package

9.4 Absolute vs. Relative Imports

# Absolute imports (preferred — clearer)
from ai_voice_studio.paths import user_data_dir
from ai_voice_studio.tts.catalog import get_tts_list
from ai_voice_studio.settings import Settings

# Relative imports (within the same package)
from . import paths            # Same package
from .. import settings         # Parent package
from .tts import catalog        # Sibling package
from ..paths import user_data_dir # Parent's module
from .models import ModelStore   # Same package's module

# In AIVS, relative imports are used within the package:
# From tts/engine.py:
from .. import paths
from ..settings import Settings

9.6 Import Hooks and Dynamic Imports

# Importlib — dynamic imports at runtime
import importlib
module = importlib.import_module("ai_voice_studio.tts.catalog")

# Used in the addon system
import importlib.util
spec = importlib.util.spec_from_file_location(
    "_addon_my_tts",
    "/path/to/addon/__init__.py",
)
module = importlib.util.module_from_spec(spec)
sys.modules["_addon_my_tts"] = module
spec.loader.exec_module(module)

# Lazy imports (import only when needed)
def heavy_function():
    import numpy  # Only imported when function is called
    return np.array([1, 2, 3])

9.8 Key Takeaways

  • Any .py file is a module; a directory with __init__.py is a package
  • Use absolute imports for clarity (from ai_voice_studio.paths import ...)
  • Relative imports are for within-package references only
  • The if __name__ == "__main__" pattern allows files to be both imported and run
  • Dynamic imports via importlib enable the AIVS addon system
  • Lazy imports (inside functions) improve startup time for heavy dependencies
