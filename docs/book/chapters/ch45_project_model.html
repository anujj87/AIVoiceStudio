Chapter 45

Project Model & Persistence

Current implementation (2026.3.1). A project's tts block now also holds omni (the OmniVoice mode, design instructions, reference clip and generation parameters) and engine_options ({"engine": id, "values": {...}}, the per-project Voice Lab overrides written by Engine tuning..., in addition to the Settings defaults). Each segment still carries index, title, text, saved and status, and those two fields are what the Start Selected Recording picker reads: a segment with saved is offered as a recorded file, every title is offered as a file break. Re-recording a file clears saved and returns the segment to pending. The recording range (start position and whether to stop after one file) is a runtime argument, deliberately not stored in the project.

Learning Objectives

  • Understand the AIVS project data model
  • Implement atomic JSON writes for crash safety
  • See the segment lifecycle (pending → done)

45.2 Atomic Writes

# From project.py — crash-safe save
def save_project(project_dir: str, data: dict) -> None:
    """Save project.json atomically (write to temp, then rename)."""
    import tempfile
    path = os.path.join(project_dir, "project.json")
    fd, tmp = tempfile.mkstemp(dir=project_dir, suffix=".tmp")
    try:
        with os.fdopen(fd, "w", encoding="utf-8") as f:
            json.dump(data, f, indent=2, ensure_ascii=False)
        os.replace(tmp, path)  # Atomic on same filesystem
    except:
        os.unlink(tmp)
        raise

def mark_segment_done(project_dir, segment_index, audio_path):
    """Mark a segment as done and save immediately."""
    data = load_project(project_dir)
    for seg in data["segments"]:
        if seg["index"] == segment_index:
            seg["status"] = "done"
            seg["saved"] = os.path.basename(audio_path)
            break
    save_project(project_dir, data)

def first_pending_index(project_dir) -> int:
    """Find the first segment that hasn't been recorded yet."""
    data = load_project(project_dir)
    for seg in data.get("segments", []):
        if seg.get("status") != "done":
            return seg["index"] - 1
    return len(data.get("segments", []))

45.3 Key Takeaways

  • A project is a JSON file with name, source, segments, and TTS settings
  • Atomic writes (temp file + rename) prevent corruption on crash
  • Segments are saved immediately after recording — reopening the project resumes where you left off
  • first_pending_index() enables seamless resume after app restart
