Chapter 28

Sizers & Layout

Learning Objectives

  • Understand wxPython's layout system (sizers)
  • Use BoxSizer, FlexGridSizer, and GridSizer
  • See layout patterns in AIVS dialogs

28.1 Why Sizers?

wxPython does not use absolute positioning. Instead, sizers automatically arrange widgets, handling resizing, padding, and alignment.

28.2 BoxSizer — The Most Common

# Vertical layout (widgets stack top to bottom)
sizer = wx.BoxSizer(wx.VERTICAL)
sizer.Add(label, 0, wx.ALL, 10)       # 0 = don't expand
sizer.Add(text_ctrl, 1, wx.EXPAND | wx.ALL, 5)  # 1 = expand proportionally
sizer.Add(button, 0, wx.ALIGN_RIGHT | wx.ALL, 5)

# Horizontal layout (widgets go left to right)
hbox = wx.BoxSizer(wx.HORIZONTAL)
hbox.Add(start_btn, 0, wx.ALL, 4)
hbox.Add(pause_btn, 0, wx.ALL, 4)
hbox.Add(stop_btn, 0, wx.ALL, 4)

# Add with proportion, flags, and border
sizer.Add(
    widget,
    proportion=1,        # Relative size (0=fixed, 1=shares space)
    flag=wx.EXPAND | wx.ALL,  # Behavior
    border=10,            # Border width in pixels
)

Sizer Flags

FlagMeaning
wx.EXPANDWidget fills available space
wx.ALLBorder on all sides
wx.LEFT/wx.RIGHT/wx.TOP/wx.BOTTOMBorder on specific sides
wx.ALIGN_CENTERCenter in available space
wx.ALIGN_RIGHTAlign to right

28.4 Layout in AIVS Recording Dialog

# From recording_dialog.py — nested sizer layout
def _build_ui(self):
    sizer = wx.BoxSizer(wx.VERTICAL)

    # Title
    title = wx.StaticText(self, label=f"Project: {title_text}")
    sizer.Add(title, 0, wx.ALL, 6)

    # Text preview
    self.text_preview = wx.TextCtrl(
        self, style=wx.TE_MULTILINE | wx.TE_READONLY, size=(-1, 130),
    )
    sizer.Add(self.text_preview, 0, wx.EXPAND | wx.LEFT | wx.RIGHT, 6)

    # Model selectors (grid layout)
    grid = wx.FlexGridSizer(cols=2, vgap=6, hgap=8)
    grid.AddGrowableCol(1)
    add_labeled(self, grid, "TTS engine", self.tts_combo)
    add_labeled(self, grid, "Language", self.lang_combo)
    add_labeled(self, grid, "Voice", self.voice_combo)
    sizer.Add(grid, 0, wx.EXPAND | wx.ALL, 6)

    # Buttons (horizontal)
    btns = wx.BoxSizer(wx.HORIZONTAL)
    btns.Add(self.start_btn, 0, wx.ALL, 4)
    btns.Add(self.pause_btn, 0, wx.ALL, 4)
    btns.Add(self.stop_btn, 0, wx.ALL, 4)
    sizer.Add(btns, 0, wx.LEFT, 2)

    # Progress bar (expands horizontally)
    self.gauge = wx.Gauge(self, range=100, size=(-1, 22))
    sizer.Add(self.gauge, 0, wx.EXPAND | wx.ALL, 6)

    self.SetSizer(sizer)

28.5 Key Takeaways

  • BoxSizer for linear layouts (vertical/horizontal)
  • FlexGridSizer for form-style layouts (label + control pairs)
  • Proportion controls how space is shared (0 = fixed, 1+ = proportional)
  • Flags control alignment, expansion, and borders
  • Nest sizers for complex layouts
