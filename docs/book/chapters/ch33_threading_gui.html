Chapter 33

Threading in GUI Applications

Learning Objectives

  • Understand why threading + GUI requires special care
  • Master the wx.PostEvent pattern for thread-safe GUI updates
  • See the complete SynthesisWorker pattern in AIVS

33.1 The Rule: Never Touch GUI from Worker Threads

Rule #1: wxPython widgets are NOT thread-safe. You must NEVER call widget methods from a worker thread. Always use wx.PostEvent() to send messages to the main thread, where the GUI handler updates the widgets. 
# ❌ WRONG — crashes or corrupts GUI
def worker(self):
    self.status_label.SetLabel("Working...")  # DANGER!

# ✓ CORRECT — post event to main thread
def worker(self):
    wx.PostEvent(self, SynthStatusEvent("Working..."))

# ✓ CORRECT — use wx.CallAfter for simple cases
def worker(self):
    wx.CallAfter(self.status_label.SetLabel, "Working...")

33.2 The Complete Pattern

The AIVS Recording Dialog demonstrates the full pattern:

# 1. Define custom events
_SYNTH_STATUS = wx.NewEventType()
EVT_SYNTH_STATUS = wx.PyEventBinder(_SYNTH_STATUS, 1)

class SynthStatusEvent(wx.PyCommandEvent):
    def __init__(self, message: str):
        super().__init__(_SYNTH_STATUS)
        self.message = message

# 2. Create the worker thread
class SynthesisWorker(threading.Thread):
    def __init__(self, ..., on_status, on_segment_done, on_all_done, on_error):
        super().__init__(daemon=True)
        self._on_status = on_status
        self._on_done = on_segment_done
        self._on_all_done = on_all_done
        self._on_error = on_error

    def run(self):
        try:
            for i, seg in enumerate(self._segments):
                self._on_status(f"Recording {seg.title}...")
                # ... synthesize ...
                self._on_done(i, seg.title, path)
            self._on_all_done()
        except Exception as exc:
            self._on_error(str(exc))

# 3. Launch from GUI (main thread)
def _on_start(self, _):
    self._worker = SynthesisWorker(
        segments=self._segments,
        on_status=lambda msg: wx.PostEvent(self, SynthStatusEvent(msg)),
        on_segment_done=lambda i, t, p: wx.PostEvent(self, SynthSegmentDoneEvent(i, t, p)),
        on_all_done=lambda: wx.PostEvent(self, SynthFinishedEvent()),
        on_error=lambda msg: wx.PostEvent(self, SynthErrorEvent(msg)),
    )
    self._worker.start()

# 4. Handle events (main thread)
self.Bind(EVT_SYNTH_STATUS, self._on_synth_status)
self.Bind(EVT_SYNTH_SEGMENT_DONE, self._on_segment_done)
self.Bind(EVT_SYNTH_FINISHED, self._on_finished)
self.Bind(EVT_SYNTH_ERROR, self._on_error)

def _on_synth_status(self, evt):
    self.status_label.SetLabel(evt.message)  # Safe — main thread

33.3 Cancel and Pause Patterns

# Using threading.Event for cancellation
self._cancel_event = threading.Event()

# Worker checks periodically
def run(self):
    for seg in self._segments:
        if self._cancel_event.is_set():
            break  # Exit gracefully
        # ... process segment ...

# GUI signals cancellation
def _on_stop(self, _):
    self._cancel_event.set()
    self.status_label.SetLabel("Stopping...")

# Pause uses a separate event
self._pause_event = threading.Event()

def run(self):
    for seg in self._segments:
        while self._pause_event.is_set():
            if self._cancel_event.is_set():
                break
            time.sleep(0.1)  # Wait while paused
        # ... process segment ...

33.4 Key Takeaways

  • Never touch GUI widgets from worker threads
  • wx.PostEvent() sends events from worker → GUI safely
  • wx.CallAfter() is a simpler alternative for single calls
  • Use threading.Event for cancel/pause signaling
  • The AIVS pattern: Worker thread → custom wx events → GUI handlers
