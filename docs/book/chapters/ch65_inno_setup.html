Inno Setup Installers

Learning Objectives

  • Understand the Inno Setup compilation process

65.1 Build Pipeline

Development venv → PyInstaller → dist/AIVS-64/ → Inno Setup → Setup.exe

# Step 1: PyInstaller bundles the app
pyinstaller packaging/ai_voice_studio.spec

# Step 2: Inno Setup wraps it into an installer
"C:\Program Files\Inno Setup 7\ISCC.exe" packaging/installer_64.iss

# Output: dist/AI-Voice-Studio-v-2026-2-0-Setup-x64.exe (39 MB)

Explain Line by Line Code Description (Block 1)

  1. Line 1: Development venv → PyInstaller → dist/AIVS-64/ → Inno Setup → Setup.exe
    A tool that packages Python apps into standalone executables. Bundles Python interpreter and all dependencies.
  2. Line 2: # Step 1: PyInstaller bundles the app
    A comment: Step 1: PyInstaller bundles the app.
  3. Line 3: pyinstaller packaging/ai_voice_studio.spec
    Command-line tool for building executables. Supports --onefile, --windowed, --add-data options.
  4. Line 4: # Step 2: Inno Setup wraps it into an installer
    A comment: Step 2: Inno Setup wraps it into an installer.
  5. Line 5: "C:\Program Files\Inno Setup 7\ISCC.exe" packaging/installer_64.iss
    A Windows installer builder. Compiles .iss scripts into setup.exe files.
  6. Line 6: # Output: dist/AI-Voice-Studio-v-2026-2-0-Setup-x64.exe (39 MB)
    A comment: Output: dist/AI-Voice-Studio-v-2026-2-0-Setup-x64.exe (39 MB).

65.2 Installer Features

  • "Install for all users" / "for me only" choice (no admin needed for per-user)
  • Install location picker
  • Start Menu folder choice
  • Optional desktop icon
  • "Open Read Me after install" checkbox
  • "Launch AI Voice Studio after setup" checkbox
  • GPL-3.0 license page
  • Uninstaller with clean removal

65.3 Inno Setup Script Structure

; packaging/installer_64.iss (simplified)
[Setup]
AppName=AI Voice Studio
AppVersion=2.0.0
DefaultDirName={autopf}\AI Voice Studio
DefaultGroupName=AI Voice Studio
LicenseFile=..\LICENSE
OutputDir=..\dist
OutputBaseFilename=AI-Voice-Studio-v-2026-2-0-Setup-x64
Compression=lzma2/ultra64
SolidCompression=yes
ArchitecturesAllowed=x64compatible
ArchitecturesInstallIn64BitMode=x64compatible

[Files]
Source: "..\dist\AIVS-64\AI-Voice-Studio\*"; DestDir: "{app}"; Flags: ignoreversion recursesubdirs

[Icons]
Name: "{group}\AI Voice Studio"; Filename: "{app}\AI-Voice-Studio.exe"
Name: "{autodesktop}\AI Voice Studio"; Filename: "{app}\AI-Voice-Studio.exe"; Tasks: desktopicon

[Run]
Filename: "{app}\AI-Voice-Studio.exe"; Description: "Launch AI Voice Studio"; Flags: nowait postinstall skipifsilent

65.4 Key Takeaways

  • Inno Setup 7 creates professional Windows installers
  • The installer wraps the PyInstaller output into a setup.exe
  • LZMA2 compression reduces the 39 MB installer size
  • The build is automated via build.ps1 (PowerShell)
  • Output: AI-Voice-Studio-v-2026-2-0-Setup-x64.exe
