Chapter 22

Type Hints & Static Typing

Learning Objectives

  • Understand type hints and their benefits
  • Use modern type hint syntax (Python 3.9-3.12)
  • See type hints throughout the AIVS codebase

22.1 Why Type Hints?

Type hints document expected types without enforcing them at runtime. Benefits:

  • IDE support — autocompletion, error detection
  • Documentation — function signatures are self-documenting
  • Catch bugs early — static type checkers (mypy, Pylance) catch type errors before runtime
  • Refactoring safety — rename a method and see all affected call sites

22.6 Key Takeaways

  • Type hints are optional documentation that help IDEs and catch bugs
  • Use Python 3.10+ syntax: str | None instead of Optional[str]
  • TypedDict for structured dicts, Callable for function types
  • AIVS uses type hints on all public function signatures
  • from __future__ import annotations enables forward references
