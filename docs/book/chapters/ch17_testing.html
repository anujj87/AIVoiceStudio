Chapter 17

Testing with unittest & pytest

Learning Objectives

  • Write unit tests with unittest and pytest
  • Use assertions effectively
  • Understand test organization and naming conventions
  • See the AIVS test suite structure

17.1 Why Test?

AI Voice Studio has 99+ tests across 12 test files. Testing ensures:

  • Correctness — code does what it's supposed to
  • Regression prevention — changes don't break existing functionality
  • Documentation — tests show how code is intended to be used
  • Confidence — refactoring safely

17.2 unittest — The Standard Library

import unittest
from ai_voice_studio.util import sanitize_filename

class SanitizeFilenameTest(unittest.TestCase):
    """Tests for the sanitize_filename utility function."""

    def test_removes_illegal_characters(self):
        """Characters illegal on Windows should be replaced."""
        result = sanitize_filename('File: "Name" <bad>?')
        assert ":" not in result
        assert '"' not in result
        assert "<" not in result

    def test_truncates_long_names(self):
        """Names exceeding max_length should be truncated."""
        long_name = "A" * 200
        result = sanitize_filename(long_name, max_length=80)
        assert len(result) <= 80

    def test_strips_whitespace(self):
        """Leading/trailing whitespace should be removed."""
        result = sanitize_filename("  hello  ")
        assert result == "hello"

    def test_empty_name_returns_fallback(self):
        """Empty names should return a valid filename."""
        result = sanitize_filename("")
        assert result  # Non-empty

# Run with: python -m unittest tests/test_util.py

17.3 pytest — The Preferred Framework

# pytest tests are simpler — just use assert statements
from ai_voice_studio.tts import catalog

def test_tts_ids_are_unique():
    """Every TTS engine must have a unique ID."""
    ids = [t["id"] for t in catalog.get_tts_list()]
    assert len(ids) == len(set(ids))

def test_required_engines_present():
    """Piper, Kokoro, and Matcha must be in the catalog."""
    ids = {t["id"] for t in catalog.get_tts_list()}
    assert "piper" in ids
    assert "kokoro" in ids
    assert "matcha" in ids

def test_piper_voices_have_artifacts():
    """Every Piper voice must have a download artifact."""
    piper = catalog.find_tts("piper")
    assert piper is not None
    for lang in piper["languages"]:
        for variant in lang["variants"]:
            assert variant.get("artifact") or variant.get("voices")

# Run with: python -m pytest tests/ -v

17.6 Key Takeaways

  • Test names should be descriptive: test_piper_voices_have_artifacts
  • setUp/tearDown create and clean up test fixtures
  • Use tempfile.TemporaryDirectory for file system tests
  • The AIVS test suite has 99+ tests across 12 files
  • pytest is simpler than unittest but unittest is in the stdlib
