Chapter 69

Logging & Diagnostics

Learning Objectives

  • Understand the AIVS logging system (basic and heavy modes)
  • See how developer mode enables detailed diagnostics
  • Understand the crash log system

69.1 Two Logging Modes

# From main.py
def _setup_logging(developer_mode=False):
    if developer_mode:
        from ai_voice_studio.heavy_logging import setup_heavy_logging
        setup_heavy_logging(enabled=True)
    else:
        logging.basicConfig(
            filename=paths.log_file(),
            level=logging.INFO,
            format="%(asctime)s %(levelname)s %(name)s: %(message)s",
        )

Basic Mode (Default)

  • INFO level logging to app.log
  • Single log file

Developer Mode (Heavy Logging)

  • DEBUG level logging
  • Multiple subsystem log files
  • Full tracebacks for all caught exceptions
  • Thread crash logging
  • Crash log for unhandled exceptions
  • System info logging (OS, Python, GPU)

69.2 Logging Best Practices in AIVS

import logging
log = logging.getLogger(__name__)

# Info: normal operations
log.info("AI Voice Studio starting (Python {sys.version.split()[0]})")

# Warning: recoverable issues
log.warning("Model not found at {path}")

# Error: failures with context
log.error("Failed to load model: {exc}", exc_info=True)

# Debug: detailed diagnostic info
log.debug("Resolved compute mode: {mode}")

69.3 Key Takeaways

  • Two modes: basic (INFO to app.log) and heavy (DEBUG to multiple files)
  • Developer mode is toggled from Settings → General
  • exc_info=True captures full tracebacks in error logs
  • Each module gets its own logger: logging.getLogger(__name__)
