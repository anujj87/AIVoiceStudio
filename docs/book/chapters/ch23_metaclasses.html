Chapter 23

Metaclasses & Descriptors

Learning Objectives

  • Understand how Python creates classes
  • Use metaclasses for class-level customization
  • Understand descriptors (the mechanism behind @property)
  • Know when to use these advanced features (and when not to)

23.1 How Python Creates Classes

# Every class has a metaclass — by default it's 'type'
class MyClass:
    pass

print(type(MyClass))     # <class 'type'>
print(type(42))         # <class 'int'>
print(type(MyClass()))   # <class 'MyClass'>

# type(name, bases, namespace) creates a class
MyClass = type("MyClass", (), {"x": 42})
print(MyClass().x)  # 42

23.2 Custom Metaclasses

class AutoRegisterMeta(type):
    """Automatically register subclasses."""
    _registry: dict[str, type] = {}

    def __new__(mcs, name, bases, namespace):
        cls = super().__new__(mcs, name, bases, namespace)
        if bases:  # Don't register the base class itself
            mcs._registry[name] = cls
        return cls

class Engine(metaclass=AutoRegisterMeta):
    pass

class PiperEngine(Engine):
    pass  # Auto-registered!

class KokoroEngine(Engine):
    pass  # Auto-registered!

print(AutoRegisterMeta._registry)
# {'PiperEngine': <class 'PiperEngine'>, 'KokoroEngine': <class 'KokoroEngine'>}

23.3 Descriptors

Descriptors are objects that define __get__, __set__, or __delete__. They power @property:

class Validated:
    """Descriptor that validates values on assignment."""

    def __init__(self, min_val: float, max_val: float):
        self.min_val = min_val
        self.max_val = max_val

    def __set_name__(self, owner, name):
        self.name = name

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        return obj.__dict__.get(self.name, 1.0)

    def __set__(self, obj, value):
        if not (self.min_val <= value <= self.max_val):
            raise ValueError(
                f"{self.name} must be between {self.min_val} and {self.max_val}"
            )
        obj.__dict__[self.name] = value

class VoiceParams:
    rate = Validated(0.5, 2.0)
    pitch = Validated(0.5, 2.0)
    volume = Validated(0.0, 2.0)

params = VoiceParams()
params.rate = 1.5   # OK
# params.rate = 5.0  # ValueError!

23.4 Key Takeaways

  • Metaclasses customize class creation — powerful but rarely needed
  • Descriptors power @property and can add validation, caching, etc.
  • In practice, prefer @property and @dataclass over metaclasses
  • AIVS doesn't use custom metaclasses — it uses composition and decorators instead
