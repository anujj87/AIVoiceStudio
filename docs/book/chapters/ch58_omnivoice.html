Chapter 58

OmniVoice TTS Engine

Learning Objectives

  • Understand the OmniVoice TTS engine (600+ languages)
  • See the two inference modes (triton vs hybrid)
  • Understand the HTTP server variant

58.1 OmniVoice Features

  • 600+ languages — massively multilingual
  • Voice cloning — zero-shot from 3-15 second sample
  • Voice design — create voices from text descriptions
  • Triton mode — stable, ~1.5x faster than stock
  • Hybrid mode — ~3.4x faster (may leak VRAM)

58.2 OmniVoiceWorker (Subprocess)

class OmniVoiceWorker:
    """Manages the OmniVoice worker subprocess."""

    def _ensure_proc(self):
        if self._proc and self._proc.poll() is None:
            return
        # In frozen app, use managed venv Python
        if getattr(sys, "frozen", False):
            from ..python_runtime import get_runtime
            rt = get_runtime()
            worker_python = rt.python_exe
            # Write standalone worker script
            worker_script = os.path.join(rt.env_dir, "_omnivoice_worker.py")
            if not os.path.isfile(worker_script):
                with open(worker_script, "w") as f:
                    f.write(_read_worker_source())
            cmd = [worker_python, worker_script]
        else:
            cmd = [sys.executable, "worker.py"]

        self._proc = subprocess.Popen(
            cmd, stdin=subprocess.PIPE, stdout=subprocess.PIPE,
            stderr=subprocess.DEVNULL, text=True,
        )
        self._request({"cmd": "ping"})

    def synthesize(self, text, speed=1.0, ref_audio="",
                   ref_text="", instruct="", language="auto"):
        req = {"cmd": "synthesize", "text": text, "speed": speed}
        if ref_audio: req["ref_audio"] = ref_audio
        if instruct: req["instruct"] = instruct
        resp = self._request(req)
        raw = base64.b64decode(resp["wav"])
        return np.frombuffer(raw, dtype=np.int16).copy()

58.4 Key Takeaways

  • OmniVoice is the most powerful TTS engine — 600+ languages, cloning, design
  • Two modes: triton (stable) and hybrid (fast, may leak VRAM)
  • The HTTP server variant allows network access and OpenAI-compatible API
  • Requires CUDA GPU — detected via nvidia-smi
  • Like XTTS, runs in a separate subprocess for runtime isolation
