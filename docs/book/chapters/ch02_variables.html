2.1 Python Is Dynamically Typed

Unlike languages such as C, Java, or Go, Python does not require you to declare the type of a variable. The type is determined at runtime based on the value assigned: 

# Python figures out the type automatically
name = "AI Voice Studio"      # str
version = 2.0                  # float
year = 2026                     # int
is_released = True              # bool
nothing = None                  # NoneType

# You can reassign to a different type (though you usually shouldn't)
x = 42       # int
x = "hello"  # now str — Python doesn't care

import re

def sanitize_filename(name: str, max_length: int = 80) -> str:
    """Remove or replace characters that are unsafe in filenames."""
    # Replace characters illegal on Windows
    name = re.sub(r'[<>:"/\\|?*]', '_', name)
    # Collapse whitespace
    name = re.sub(r'\s+', ' ', name).strip()
    # Truncate to max length
    if len(name) > max_length:
        name = name[:max_length].rstrip()
    return name

2.14 Key Takeaways

  • Python is dynamically typed — variables have no declared type, but every value has a type
  • Five core types: int, float, bool, str, None
  • Integers have arbitrary precision — no overflow
  • Floats have limited precision — never use == for comparison
  • Strings are immutable — operations create new strings
  • Use is for None comparison, == for value equality
  • Constants go in UPPER_SNAKE_CASE and live in a dedicated module
  • Type hints document expected types without enforcing them
  • F-strings are the modern way to format strings
