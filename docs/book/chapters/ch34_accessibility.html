Accessibility (a11y)

Learning Objectives

  • Understand why accessibility matters in desktop apps
  • Make wxPython apps accessible with SetName() and proper labels
  • See the AIVS a11y helper system

34.1 What Is Accessibility?

Accessibility (a11y) ensures that people with disabilities can use your software. For a text-to-speech application like AIVS, this is especially important because many users rely on screen readers (NVDA, JAWS, Narrator).

34.2 wxPython Accessibility Basics

34.3 AIVS a11y Helper

# From gui/a11y.py
def add_labeled(parent, sizer, label_text, control, **kwargs):
    """Add a label-control pair with screen reader support."""
    label = wx.StaticText(parent, label=label_text + ":")
    _tint(label)  # Apply theme colors
    sizer.Add(label, 0, wx.ALIGN_CENTER_VERTICAL | wx.ALL, 4)
    control.SetName(label_text)  # Set accessible name
    sizer.Add(control, 1, wx.EXPAND | wx.ALL, 4)
    return label

def add_check(parent, sizer, label_text, checked=False):
    """CheckBox with accessible name."""
    box = wx.CheckBox(parent, label=label_text)
    box.SetValue(checked)
    box.SetName(label_text)
    sizer.Add(box, 0, wx.ALL, 4)
    return box

def set_accessible_name(control, name):
    control.SetName(name)

34.4 Tab Order and Focus

# Tab order follows creation order in the sizer
# AIVS puts the text preview first so screen readers
# announce the content before the controls

# Announce page changes in wizards
def _on_page_changed(self, evt):
    page = evt.GetPage()
    if evt.GetDirection():  # Forward
        if page is self.page_details:
            self.page_details.name_ctrl.SetFocus()
    evt.Skip()

# Set initial focus when dialogs open
self.SetName(f"Recording: {project_name}")
wx.CallAfter(self.text_preview.SetFocus)

34.5 Key Takeaways

  • SetName() is the most important accessibility method — it provides the screen reader label
  • Every interactive control needs a descriptive name
  • Tab order should be logical (content first, then controls)
  • AIVS has a dedicated a11y.py module with helpers for accessible controls
  • The AIVS project was designed with accessibility as a core requirement
