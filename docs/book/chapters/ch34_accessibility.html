34.1 What Is Accessibility?

Accessibility (a11y) ensures that people with disabilities can use your software. For a text-to-speech application like AIVS, this is especially important because many users rely on screen readers (NVDA, JAWS, Narrator).

34.5 What Changed Since the First Edition: Real MSAA Names

The first edition relied on wx.Control.SetName() and labels. Testing with real screen readers showed that SetName alone does not produce an MSAA accName for every control class — some controls (gauges, read-only text, static labels in sizers) still announced as "pane" or their class name. The helper module now attaches a real wx.Accessible implementation:

class _NameAccessible(wx.Accessible):
    def __init__(self, win: wx.Window):
        super().__init__(win)
        self._win = win

    def GetName(self, childId):
        name = self._win.GetName()
        if childId == 0 and name:
            return (wx.ACC_OK, name, 0)
        return (wx.ACC_FAIL, "", 0)

    def GetChildCount(self):
        return 0


def set_accessible_name(control: wx.Window, name: str) -> None:
    control.SetName(name)
    if not control.GetAccessible():
        control.SetAccessible(_NameAccessible(control))


def update_accessible_name(control: wx.Window, name: str) -> None:
    control.SetName(name)
    acc = control.GetAccessible()
    if acc is not None:
        acc.NotifyEvent(wx.OBJ_CHANGE, 0)


def finalize_accessibility(container: wx.Window) -> None:
    def walk(win: wx.Window) -> None:
        if win.GetName():
            set_accessible_name(win, win.GetName())
        for child in win.GetChildren():
            walk(child)
    walk(container)

Explain Line by Line Code Description (Block 5)

  1. Lines 1–4: class _NameAccessible(wx.Accessible):
    A minimal MSAA provider. Subclassing wx.Accessible and attaching it to a window is the official wxPython way to answer the screen reader's IAccessible::get_accName call with a real string — no more reliance on heuristics that differ per control class.
  2. Lines 6–9: def GetName(self, childId):
    The one method screen readers call constantly. It returns a tuple: (wx.ACC_OK, the window's name, child id 0). When the reader hovers or focuses the control, this is the name it announces. Returning wx.ACC_FAIL for the object-without-name case lets wx fall back to its own behaviour instead of announcing an empty string.
  3. Lines 11–12: def GetChildCount(self): return 0
    Declares the control atomic — no MSAA children to enumerate. This keeps NVDA from descending into leaf controls looking for child elements that do not exist.
  4. Lines 15–18: def set_accessible_name(control, name):
    The single entry point every widget builder calls. It does both halves: SetName(name) (used by wx itself and by tests) and attaches the MSAA provider exactly once — GetAccessible() is checked so repeated calls never stack duplicate providers.
  5. Lines 21–25: def update_accessible_name(control, name):
    For controls whose label changes at runtime (the Rate/Pitch/Volume sliders announce "Rate: 1.35"). After updating the name it fires acc.NotifyEvent(wx.OBJ_CHANGE, 0), which pushes an MSAA event so a focused screen reader re-announces the new value as the slider moves — without the event, NVDA would keep reading the stale label.
  6. Lines 28–33: def finalize_accessibility(container):
    A depth-first walk over the widget tree at dialog-construction time: every window that carries a name gets the MSAA provider attached. One call in each dialog's __init__ guarantees full coverage, so individual builders cannot forget a control.
Audit tooling: tools/probe_msaa.py and tools/a11y_audit.py launch the real dialogs and dump the MSAA tree, so every accName is verified against what NVDA actually sees — not what the source code hopes it sees.

34.6 Key Takeaways

  • SetName() alone is not enough for every control class — a real wx.Accessible guarantees the MSAA accName
  • Runtime label changes need NotifyEvent(wx.OBJ_CHANGE) to be re-announced
  • finalize_accessibility() walks the whole tree so no control is missed
  • Verify with tools (probe_msaa.py), not assumptions
  • The AIVS project was designed with accessibility as a core requirement
