18.1 JSON in Depth

import json

# Python ↔ JSON type mapping
# dict    →  object
# list    →  array
# str     →  string
# int/float → number
# True    →  true
# False   →  false
# None    →  null

# Complex serialization
data = {
    "name": "My Project",
    "segments": [
        {"index": 1, "title": "Chapter 1", "text": "..."},
        {"index": 2, "title": "Chapter 2", "text": "..."},
    ],
    "tts": {
        "voice": "af_bella",
        "rate": 1.0,
        "pitch": 1.0,
    },
}

# Serialize with nice formatting
json_str = json.dumps(data, indent=2, ensure_ascii=False)
print(json_str)

# Deserialize
loaded = json.loads(json_str)

# Write to file
with open("project.json", "w", encoding="utf-8") as f:
    json.dump(data, f, indent=2, ensure_ascii=False)

# Read from file
with open("project.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)

18.4 Structured Data Patterns

# Pattern: Default dict with deep merge
def deep_merge(base: dict, override: dict) -> dict:
    """Merge two dicts, with override taking precedence."""
    result = dict(base)
    for key, value in override.items():
        if key in result and isinstance(result[key], dict) and isinstance(value, dict):
            result[key] = deep_merge(result[key], value)
        else:
            result[key] = value
    return result

# Pattern: Typed dict for structured data
from typing import TypedDict

class SegmentDict(TypedDict, total=False):
    index: int
    title: str
    text: str
    status: str
    saved: str
    duration: float

18.5 Key Takeaways

  • JSON is the primary data format in AIVS — settings, projects, and worker protocols all use it
  • json.dumps/loads for strings; json.dump/load for files
  • Always use ensure_ascii=False for Unicode text
  • XML is used for DAISY 2.02 book structure (NCC, OPF, SMIL files)
  • The worker protocol uses JSON lines (one JSON object per line)
