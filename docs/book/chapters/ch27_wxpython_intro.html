27.1 What Is wxPython?

wxPython is a Python wrapper around the wxWidgets C++ GUI toolkit. It provides native-looking widgets on each platform — Windows controls look like Windows controls, macOS controls look like macOS controls, etc.

FeaturewxPythonTkinterPyQt
Native look?Yes (wraps native widgets)No (custom rendering)Mostly
LicensewxWindows (permissive)PSF (Python)GPL/Commercial
AccessibilityGood (MSAA/UIA on Windows)BasicGood
Learning curveModerateEasySteep

27.2 Hello wxPython

import wx

class MyFrame(wx.Frame):
    def __init__(self):
        super().__init__(
            None,
            title="Hello wxPython",
            size=(400, 300),
        )
        panel = wx.Panel(self)
        label = wx.StaticText(panel, label="Hello, World!")
        sizer = wx.BoxSizer(wx.VERTICAL)
        sizer.Add(label, 0, wx.ALL, 20)
        panel.SetSizer(sizer)

# Application entry point
app = wx.App(False)
frame = MyFrame()
frame.Show()
app.MainLoop()

27.4 The AIVS MainFrame

# From gui/main_frame.py
class MainFrame(wx.Frame):
    def __init__(self, parent, settings: Settings, store: ModelStore):
        super().__init__(
            parent,
            title=f"{APP_NAME} v{APP_VERSION}",
            size=(800, 600),
        )
        self.settings = settings
        self.store = store

        self._build_menu()
        self._build_ui()
        self._bind_events()

        self.Centre()
        self.SetStatusText("Ready")

    def _build_menu(self):
        """Build the menu bar with File, Edit, Tools, Settings, Help."""
        menubar = wx.MenuBar()

        # File menu
        file_menu = wx.Menu()
        file_menu.Append(ID_NEW_PROJECT, "&New Project\tCtrl+Shift+N")
        file_menu.Append(ID_OPEN_PROJECT, "&Open Project\tCtrl+O")
        file_menu.AppendSeparator()
        file_menu.Append(wx.ID_EXIT, "E&xit\tAlt+F4")
        menubar.Append(file_menu, "&File")

        # Tools menu
        tools_menu = wx.Menu()
        tools_menu.Append(ID_RECORD, "&Record\tCtrl+Shift+R")
        menubar.Append(tools_menu, "&Tools")

        # Settings menu
        settings_menu = wx.Menu()
        settings_menu.Append(ID_SETTINGS, "&Settings\tCtrl+,")
        menubar.Append(settings_menu, "&Settings")

        self.SetMenuBar(menubar)

27.5 The Widget Hierarchy

wx.App                          # Application object
└── wx.Frame                    # Window
    ├── wx.MenuBar              # Menu bar
    │   ├── wx.Menu             # Drop-down menu
    │   │   └── wx.MenuItem     # Menu item
    ├── wx.Panel                # Container panel
    │   ├── wx.StaticText       # Label
    │   ├── wx.TextCtrl         # Text input
    │   ├── wx.Button           # Button
    │   ├── wx.ComboBox         # Drop-down combo
    │   ├── wx.CheckBox         # Checkbox
    │   ├── wx.RadioButton      # Radio button
    │   ├── wx.Slider           # Slider
    │   ├── wx.Gauge            # Progress bar
    │   └── wx.ListBox          # List box
    └── wx.StatusBar            # Status bar

27.6 Key Takeaways

  • wx.App manages the event loop; create exactly one
  • wx.Frame is the main window with menus, status bar
  • Widgets are organized in a parent-child hierarchy
  • AIVS MainFrame has 5 menus (File, Edit, Tools, Settings, Help)
  • wxPython provides native widgets with platform-specific appearance
