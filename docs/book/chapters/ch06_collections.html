6.1 Lists — Ordered, Mutable Sequences

# Creating lists
engines = ["Piper", "Kokoro", "Matcha", "Kitten"]

Dictionaries in AIVS Settings

# From ai_voice_studio/settings.py
class Settings:
    def __init__(self):
        self._data: dict = {
            "theme": "system",
            "audio_mode": "page_with_h1",
            "recording.rate": 1.0,
            "recording.pitch": 1.0,
            "recording.volume": 1.0,
            "recording.output_format": "wav",
            "developer_mode": False,
        }

    def get(self, key: str, default=None):
        """Dot-notation get: settings.get('recording.rate')"""
        keys = key.split(".")
        obj = self._data
        for k in keys:
            if isinstance(obj, dict):
                obj = obj.get(k)
                if obj is None:
                    return default
            else:
                return default
        return obj

    def set(self, key: str, value):
        """Dot-notation set: settings.set('recording.rate', 1.5)"""
        keys = key.split(".")
        obj = self._data
        for k in keys[:-1]:
            obj = obj.setdefault(k, {})
        obj[keys[-1]] = value

6.5 Choosing the Right Collection

NeedUseWhy
Ordered sequence, mutablelistIndex access, append, sort
Ordered sequence, immutabletupleHashable, slightly faster
Key-value mappingdictO(1) lookup by key
Unique elements, fast membershipsetO(1) in test
Record with named fieldsnamedtupleReadable, immutable
Fixed-structure record@dataclassMutable, type-hinted (Ch 10)

6.9 Key Takeaways

  • Lists for ordered, mutable sequences (most common)
  • Tuples for fixed records and dict keys
  • Dicts for key-value data (the backbone of AIVS settings and catalog)
  • Sets for unique elements and fast membership testing
  • Copy correctly — b = a creates a reference, not a copy
  • Dict.get() with a default avoids KeyError
  • The AIVS catalog is a deeply nested dict structure: TTS → language → variant → voice
