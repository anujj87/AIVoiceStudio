Chapter 56

Background Synthesis Worker

Current implementation (2026.3.1). SynthesisWorker gained an optional exclusive end_index: with it set the worker stops cleanly after that one segment, which is what makes “only record the selected file” possible; with it None it records from the start position to the end of the project, the original behaviour. Either way playback of the run is unchanged — progress events, instant disk save per segment and the resume-from-first-unsaved rule all still apply, and after the last segment the playlists / DAISY files are written as before.

Learning Objectives

  • Understand the complete SynthesisWorker implementation
  • See how audio is synthesized, processed, and saved
  • Understand the resume-after-crash pattern

56.1 SynthesisWorker Thread

class SynthesisWorker(threading.Thread):
    """Background thread that synthesizes all segments."""

    def __init__(self, segments, voice_entry, params, output_dir,
                 start_index, on_segment_done, on_all_done, on_error,
                 cancel_event, pause_event, on_status, ffmpeg_exe=None):
        super().__init__(daemon=True)
        self._segments = segments
        self._voice_entry = voice_entry
        self._params = params
        self._output_dir = output_dir
        self._start_index = start_index
        self._on_done = on_segment_done
        self._on_all_done = on_all_done
        self._on_error = on_error
        self._cancel = cancel_event
        self._pause = pause_event
        self._on_status = on_status
        self._ffmpeg_exe = ffmpeg_exe

    def run(self):
        try:
            engine = get_engine(self._voice_entry)

            for i, seg in enumerate(self._segments):
                # Check cancellation
                if self._cancel.is_set():
                    break

                # Check pause
                while self._pause.is_set():
                    if self._cancel.is_set():
                        break
                    time.sleep(0.1)

                # Synthesize
                self._on_status(f"Recording segment {seg.index}...")
                audio = engine.synthesize(
                    seg.text,
                    speed=self._params["rate"],
                    pitch=self._params["pitch"],
                    volume=self._params["volume"],
                )

                # Save audio
                filename = sanitize_filename(seg.title) + ".wav"
                path = os.path.join(self._output_dir, filename)
                write_wav(path, audio, engine.sample_rate)

                # Convert if needed
                if self._params["output_format"] != "wav" and self._ffmpeg_exe:
                    fmt = self._params["output_format"]
                    out_path = path.replace(".wav", f".{fmt}")
                    convert_wav(path, out_path, fmt, self._ffmpeg_exe)
                    path = out_path

                # Mark segment done (saves to project.json)
                self._on_done(seg.index, seg.title, path)

            self._on_all_done()

        except Exception as exc:
            self._on_error(str(exc))

56.3 Key Takeaways

  • The worker is a daemon thread — dies with the main process
  • Immediate save after each segment enables crash recovery
  • Cancel exits after the current segment; Pause waits between segments
  • Audio goes through: synthesize → pitch/volume → save WAV → convert (optional)
  • The resume pattern: first_pending_index() → skip done segments → continue
