39.1 What Is sherpa-onnx?

sherpa-onnx is a C++ speech processing library with Python bindings, using the ONNX runtime for inference. It supports multiple TTS model formats:

  • VITS — used by Piper voices
  • Kokoro — multi-speaker multi-language
  • Matcha — flow-matching TTS with vocoder
  • Kitten — small efficient models

39.2 TTS Engine Wrapper in AIVS

# From tts/engine.py — simplified
import sherpa_onnx
import numpy as np

class TtsEngine:
    """Wrapper around sherpa-onnx TTS."""
    sample_rate = 24000

    def __init__(self, voice_entry: dict):
        files = resolve_voice_files(voice_entry)
        config = sherpa_onnx.OfflineTtsConfig(
            model=sherpa_onnx.OfflineTtsModelConfig(
                vits=sherpa_onnx.OfflineTtsVitsModelConfig(
                    model=files["model"],
                    tokens=files["tokens"],
                    data_dir=files.get("data_dir", ""),
                    lexicon=files.get("lexicon", ""),
                    dict_dir=files.get("dict_dir", ""),
                ),
                num_threads=1,
            ),
            max_num_sentences=1,
        )
        self._tts = sherpa_onnx.OfflineTts(config)

    def synthesize(self, text, sid=0, speed=1.0, pitch=1.0, volume=1.0):
        if not text.strip():
            raise ValueError("Nothing to synthesize")

        # Core synthesis
        audio = self._tts.generate(text=text, sid=sid, speed=speed)
        samples = np.array(audio.samples, dtype=np.int16)

        # Apply post-processing
        if pitch != 1.0:
            samples = _shift_pitch(samples, pitch)
        if volume != 1.0:
            samples = _apply_volume(samples, volume)

        return samples

# Engine caching (one engine per voice)
_engine_cache: dict[str, TtsEngine] = {}

def get_engine(voice_entry: dict) -> TtsEngine:
    """Get or create a cached engine."""
    key = voice_entry.get("voice", "")
    if key not in _engine_cache:
        _engine_cache[key] = TtsEngine(voice_entry)
    return _engine_cache[key]

39.4 Key Takeaways

  • sherpa-onnx is the primary TTS engine — supports VITS, Kokoro, Matcha, Kitten
  • Engine caching prevents reloading models for each synthesis call
  • resolve_voice_files() maps voice entries to actual file paths
  • The catalog is a nested dict: TTS → language → variant → voice
  • Post-processing (pitch, volume) is applied after synthesis
