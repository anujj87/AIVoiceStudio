Introspection & Reflection

Learning Objectives

  • Examine objects at runtime with dir(), type(), getattr()

  • See introspection patterns in AIVS addon system

25.1 Inspecting Objects

# dir() — list all attributes
class Settings:
    def __init__(self):
        self.theme = "dark"
        self._data = {}

s = Settings()
print(dir(s))  # Lists all attributes and methods

# type() — get the type
print(type(s))  # <class 'Settings'>

# getattr/setattr — dynamic attribute access
print(getattr(s, "theme"))           # "dark"
print(getattr(s, "missing", "default"))  # "default"
setattr(s, "volume", 0.8)
print(hasattr(s, "volume"))          # True

# inspect module — deep inspection
import inspect

# Get source code
print(inspect.getsource(Settings.__init__))

# Get function signature
sig = inspect.signature(sanitize_filename)
print(sig)  # (name: str, max_length: int = 80) -> str

# Get all members of a module
for name, obj in inspect.getmembers(catalog):
    if inspect.isfunction(obj):
        print(f"Function: {name}")

25.2 Introspection in the Addon System

# From addons/__init__.py — dynamic module loading
import importlib.util

def _register_engine(self, manifest, addon_dir):
    """Import and cache the addon's engine class."""
    module_name, class_name = manifest.engine_entry_point.split(":")
    full_path = os.path.join(addon_dir, module_name + ".py")

    # Dynamic import from file
    spec = importlib.util.spec_from_file_location(
        f"_aivs_engine_{manifest.engine_id}",
        full_path,
    )
    if spec and spec.loader:
        module = importlib.util.module_from_spec(spec)
        sys.modules[f"_aivs_engine_{manifest.engine_id}"] = module
        spec.loader.exec_module(module)

        # Get class by name (introspection)
        engine_class = getattr(module, class_name, None)
        if engine_class:
            self._engines[manifest.engine_id] = {
                "class": engine_class,
                "manifest": manifest,
            }

25.3 Key Takeaways

  • dir() lists attributes; getattr() accesses them dynamically
  • inspect module provides deep reflection (source code, signatures, members)
  • The AIVS addon system uses importlib for dynamic module loading
  • Introspection is powerful but should be used judiciously
