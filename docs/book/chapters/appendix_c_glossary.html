Appendix C: Glossary of Terms

A comprehensive glossary of technical terms used throughout this book, covering Python, wxPython, AI/TTS, audio processing, and packaging concepts.

A

Accessibility (a11y)
The design practice of making software usable by people with disabilities. In wxPython, this includes screen reader support via accessible names, roles, and descriptions. The a11y abbreviation comes from counting the letters between 'a' and 'y' in "accessibility."
ACB (Audio Callback)
In sherpa-onnx, an audio callback receives synthesized audio samples from the TTS engine. The callback is invoked from a background thread whenever a chunk of audio is ready for output.
Aggregator
In the AIVoiceStudio catalog system, an aggregator fetches and caches model catalogs from multiple upstream sources (Piper, Coqui, etc.) and provides a unified interface for querying available models.
Async/Await
Python's built-in asynchronous programming syntax. async def defines a coroutine function, and await suspends execution until an awaitable (coroutine, Future, Task) completes. Used with asyncio for non-blocking I/O operations.
Attribute
A variable associated with an object or class. In Python, attributes are accessed with dot notation (e.g., obj.attr). Class attributes are shared; instance attributes are per-object.
Augmented Assignment
Compound assignment operators that combine an operation with assignment: +=, -=, *=, /=, %=, **=, //=, etc.

B

Backend
In AIVoiceStudio, the compute backend refers to the hardware accelerator used for TTS inference: CPU, CUDA (NVIDIA GPU), DirectML (Windows ML), or CoreML (Apple). Also refers to sherpa-onnx's execution provider configuration.
Background Thread
A thread that runs concurrently with the main (GUI) thread, used for long-running operations like TTS synthesis, file downloads, or model loading. In wxPython, background threads must use wx.CallAfter to update the GUI safely.
Base64
A binary-to-text encoding scheme that represents binary data using 64 ASCII characters. Used in web APIs and configuration to embed binary data (like audio samples) in text format.
Benchmark
A standardized test that measures the performance of hardware or software. In AIVoiceStudio, compute benchmarks measure how fast TTS inference runs on different backends (CPU vs. GPU).
Binder
In wxPython, a binder associates an event type with a handler function. self.Bind(wx.EVT_BUTTON, self.on_click, self.my_button) tells wxPython to call on_click when the button is clicked.
BOM (Byte Order Mark)
A special Unicode character (U+FEFF) placed at the beginning of a text file to indicate its encoding and byte order. UTF-8 BOM is common in Windows-generated text files.
Bytecode
Intermediate compiled representation of Python source code. Python compiles .py files to .pyc bytecode files in __pycache__/, which the interpreter executes faster than raw source.

C

Callback
A function passed as an argument to another function, to be called when an event occurs or an operation completes. In sherpa-onnx TTS, audio callbacks receive synthesized audio chunks.
Casting
Converting a value from one type to another: int("42"), float(5), str(3.14). Also called type conversion.
Catalog
In AIVoiceStudio, the TTS catalog is a registry of all available voice models, organized by provider (Piper, Coqui), language, and quality. Stored as a JSON file with metadata for each model.
CLI (Command-Line Interface)
A text-based interface for interacting with software. Python's argparse module provides CLI argument parsing. AIVoiceStudio uses CLI for its build scripts.
Comprehension
A concise syntax for creating lists, dicts, or sets from iterables: [x**2 for x in range(10)] (list), {k: v for k, v in items} (dict), {x for x in items} (set). Also generator expressions with parentheses.
Context Manager
An object that implements __enter__ and __exit__ methods for use with the with statement. Ensures proper resource acquisition and cleanup. Examples: open(), threading.Lock(), wxPython's BusyCursor.
Compute
In AIVoiceStudio, refers to the hardware and software stack used for AI inference. Detected via compute.py which probes for CUDA, DirectML, CoreML, and CPU capabilities using py-cpuinfo and onnxruntime.
CUDA
NVIDIA's parallel computing platform for GPU-accelerated computation. When CUDA is available, sherpa-onnx can use it for much faster TTS synthesis. Detected by checking for CUDA runtime libraries.
Coroutine
A function defined with async def that can be paused and resumed. Coroutines are scheduled on the event loop and cooperatively yield control at await points.
CPython
The reference implementation of Python, written in C. Most Python installations use CPython. Identified by sys.implementation.name == "cpython".
Custom Event
In wxPython, a user-defined event type created with wx.NewEventType() and wx.PyEventBinder(). Used for thread-safe communication between background workers and the GUI.

D

DAISY
Digital Accessible Information System — a technical standard for accessible digital publications. AIVoiceStudio's DAISY builder creates multi-level audio publications with navigation from document chapters.
Dataclass
A Python decorator (@dataclass) that automatically generates __init__, __repr__, __eq__, and other methods from class attribute annotations. Used extensively in AIVoiceStudio for configuration and data models.
Decorator
A function that takes a callable and returns a modified callable. Used with @decorator syntax above function or class definitions. Examples: @property, @staticmethod, @dataclass, @functools.lru_cache.
Desktop Application
A graphical application that runs locally on a user's computer, as opposed to a web application. AIVoiceStudio is a desktop app built with wxPython and packaged with PyInstaller.
DirectML
Microsoft's Direct Machine Learning API for hardware-accelerated AI inference on Windows. Works with any DirectX 12-compatible GPU, not just NVIDIA. Available via onnxruntime-directml.
Docstring
A string literal placed as the first statement in a module, class, or function to document its purpose. Triple-quoted: """Docstring.""". Accessible via __doc__ and the help() function.
DPI (Dots Per Inch)
A measure of display resolution. High-DPI displays (Retina, 4K) require special handling in desktop apps. wxPython supports DPI awareness through system settings and scaling.
Dunder Method
Special methods with double underscores: __init__, __str__, __repr__, __len__, __getitem__, etc. Also called magic methods. They define how objects behave with built-in operations.

E

Enumerate
A built-in function that returns pairs of (index, value) from an iterable: for i, val in enumerate(items). Avoids manual counter management.
Event
In GUI programming, an event represents a user action (click, keypress) or system occurrence (timer, resize). wxPython events carry data and are dispatched to bound handler functions.
Event Loop
The core mechanism of a GUI framework that continuously polls for events and dispatches them to handlers. wxPython's MainLoop() runs the event loop. The application blocks at this call until the window is closed.
Event Binder
In wxPython, wx.PyEventBinder creates bindable event types. Used to associate custom events with handler methods: self.Bind(MY_EVENT, self.handler).
Exception
An error that occurs during program execution. Python uses exceptions for error handling with try/except/finally. Exceptions are objects of classes inheriting from BaseException.
Execution Provider
In ONNX Runtime, the execution provider specifies the hardware backend: CPUExecutionProvider, CUDAExecutionProvider, DmlExecutionProvider, CoreMLExecutionProvider.
Expression
A piece of code that evaluates to a value. Examples: 2 + 3, "hello".upper(), [x for x in range(5)]. Distinguished from statements, which don't return values.
Extension
A file suffix indicating file type: .py for Python, .wav for audio, .json for data. Python maps extensions to interpreters; in wxPython, extensions are used for file dialog filters.

F

F-String
Formatted string literals (Python 3.6+): f"Hello, {name}!". Support expressions inside curly braces: f"{price:.2f}". Faster and more readable than .format() or % formatting.
Factory Function
A function that creates and returns objects, serving as an alternative to constructors. In wxPython, many widget creation functions act as factories.
Fallback
A default value or behavior used when the preferred option is unavailable. In AIVoiceStudio, compute detection falls back through CUDA → DirectML → CPU if higher-performance backends aren't available.
FFmpeg
A powerful open-source multimedia framework for audio/video processing. AIVoiceStudio uses FFmpeg for audio format conversion (MP3, OGG, FLAC, WAV) and audio normalization.
Frame
In wxPython, a Frame is a top-level window with a title bar, menu bar, and close button. wx.Frame is the base class. AIVoiceStudio's main window is a Frame subclass.
Function
A reusable block of code defined with def. Functions can accept parameters, return values, and be passed as arguments. Python functions are first-class objects.
Functor
An object that can be "called" like a function by implementing __call__. Used in AIVoiceStudio for callback objects that need to maintain state between invocations.

G

Garbage Collection
Python's automatic memory management that reclaims memory from objects no longer in use. Uses reference counting plus a cyclic garbage collector for objects with circular references.
Generator
A function using yield that produces values lazily, one at a time. Generators are memory-efficient for large datasets and support the iterator protocol.
GPU (Graphics Processing Unit)
A specialized processor for parallel computation. NVIDIA GPUs support CUDA for AI inference, providing 10-50x speedup over CPU for TTS synthesis.
GridBagSizer
A wxPython layout manager that positions widgets in a grid with flexible row/column spanning. Used in AIVoiceStudio's settings dialog for complex form layouts.
Guard Clause
An early return statement that handles error conditions at the top of a function, reducing nesting. A common Python pattern: if not valid: return instead of wrapping the rest in if valid:.

H

Hash
A fixed-size value computed from data using a hash function. Python's built-in hash() is used for dictionary keys and set membership. __hash__ defines custom hashing.
Heap
Memory area where Python allocates objects. Also refers to the heapq module for priority queues. In AIVoiceStudio, heavy logging uses heap memory tracking.
HFS+ / APFS
Apple's file system formats (Hierarchical File System Plus / Apple File System). Relevant for macOS path handling and case-sensitivity differences.
Hungarian Notation
A naming convention that prefixes variable names with their type: nCount (integer), strName (string), btnOK (button). Common in wxPython codebases.

I

Idle Event
In wxPython, wx.EVT_IDLE fires when the event loop has no pending events. Used for deferred operations and periodic updates without explicit timers.
Import
The import statement loads modules and their contents into the current namespace. Forms: import os, from os import path, from os import path as p.
INI File
A simple text file format for configuration with sections and key-value pairs. Python's configparser module reads and writes INI files. AIVoiceStudio uses them for user settings.
Instance
A specific object created from a class definition. Each instance has its own attributes but shares the class methods. Created by calling the class: obj = MyClass().
Inheritance
A mechanism where a class (child/subclass) inherits attributes and methods from another class (parent/superclass). Supports code reuse and polymorphism. Python supports multiple inheritance.
Installer
A program that installs software on a user's computer. AIVoiceStudio uses Inno Setup to create a Windows installer that copies files, creates shortcuts, and registers the application.
Iterable
Any object that can be iterated over, implementing __iter__ or __getitem__. Includes lists, tuples, strings, dicts, sets, generators, and files.
Iterator
An object implementing __iter__ (returning itself) and __next__ (returning the next value). Used by for loops internally. Created by iter() function.
ISCC
Inno Setup Compiler Command-line. Used to compile .iss scripts into setup executables: "C:\Program Files\Inno Setup 7\ISCC.exe" script.iss.

J

JSON (JavaScript Object Notation)
A lightweight data interchange format. Python's json module provides dumps()/loads() for serialization/deserialization. AIVoiceStudio uses JSON for settings, catalogs, and project files.
Job Queue
A data structure for managing tasks to be processed sequentially or in parallel. In AIVoiceStudio, synthesis jobs are queued and processed by background workers with progress callbacks.
Join
String method that concatenates iterable elements: ", ".join(words). Also refers to thread.join() which blocks until a thread completes, and SQL joins for database queries.

K

Keyword Argument
A function argument passed with a name: func(name="Alice", age=30). Allows explicit argument naming, default values, and arbitrary order. Syntax: **kwargs captures keyword arguments as a dict.
Keystroke
A key press event in wxPython. wx.KeyEvent carries the key code, modifiers (Ctrl, Shift, Alt), and Unicode character. AIVoiceStudio binds keyboard shortcuts for common operations.

L

Lambda
An anonymous function: lambda x: x * 2. Limited to a single expression. Commonly used for short callbacks, sorted() keys, and map()/filter() operations.
Lifecycle
The stages an object goes through from creation to destruction. In wxPython widgets: construction → adding to sizer → show → hide → destroy. In AIVoiceStudio projects: new → open → edit → save → close.
LSP (Language Server Protocol)
A protocol for communication between code editors and language analysis tools. Provides features like autocompletion, error checking, and go-to-definition.
LUT (Lookup Table)
A data structure that maps keys to values for fast retrieval. Python dicts are hash-based LUTs with O(1) average lookup. In audio processing, LUTs map sample values for effects processing.

M

MainLoop
wxPython's event loop that runs until the application exits. Called as app.MainLoop(). Blocks the calling thread while dispatching events to handlers.
Memoryview
A built-in type that provides a typed, buffer-protocol view of binary data without copying. Useful for zero-copy slicing of large byte buffers in audio processing.
Metaclass
A class whose instances are classes. type is the default metaclass. Custom metaclasses can modify class creation. Used in wxPython for event system internals and in ORMs for model definitions.
Method Resolution Order (MRO)
The order in which Python looks up methods in a class hierarchy with multiple inheritance. Determined by the C3 linearization algorithm. Accessible via ClassName.__mro__.
MIME
Multipurpose Internet Mail Extensions. A standard for classifying file types. wxPython uses MIME types for drag-and-drop operations and clipboard data.
Module
A .py file containing Python definitions and statements. Modules provide namespaces for organizing code. The __name__ attribute identifies the module; "__main__" indicates direct execution.
Multiprocessing
Running code in separate processes, each with its own Python interpreter and memory space. Bypasses the GIL for CPU-bound parallelism. Python's multiprocessing module provides the API.
Mutability
Whether an object can be modified after creation. Lists, dicts, and sets are mutable; strings, tuples, and ints are immutable. Mutable default arguments in functions are a common pitfall.

N

Namespace
A mapping from names to objects. Each module, class, and function has its own namespace. The LEGB rule (Local, Enclosing, Global, Built-in) determines name resolution.
NIL / None
In Python, None represents the absence of a value. It's a singleton — only one instance exists. Commonly used as a default parameter and sentinel value.
Numpy
A numerical computing library providing N-dimensional arrays, mathematical functions, and linear algebra operations. AIVoiceStudio uses numpy for audio sample array manipulation.
Nuitka
A Python-to-C compiler that translates Python code to optimized C/C++ for distribution. An alternative to PyInstaller for creating standalone executables.

O

O(n) / Big-O Notation
Mathematical notation describing algorithm complexity. O(1) = constant, O(n) = linear, O(n²) = quadratic, O(log n) = logarithmic. Dict lookup is O(1); list search is O(n).
Object
The fundamental unit of Python — everything is an object, including functions, classes, and modules. Objects have identity (id()), type (type()), and attributes.
OmniVoice
An advanced TTS engine in AIVoiceStudio supporting voice cloning. Uses a server-client architecture where the OmniVoice server runs inference and the worker communicates via HTTP.
ONNX (Open Neural Network Exchange)
An open format for representing machine learning models. sherpa-onnx uses ONNX models for TTS inference, enabling cross-platform deployment with multiple execution providers.
OpenCV
An open-source computer vision library. Not directly used in AIVoiceStudio, but similar to how sherpa-onnx uses pre-compiled native libraries for performance-critical operations.
Operator Overloading
Defining how custom objects respond to built-in operators via dunder methods: __add__ for +, __eq__ for ==, __lt__ for <. Enables intuitive syntax for custom types.
Output Buffer
A memory region where audio samples are accumulated before being written to a file or played. In AIVoiceStudio's TTS engine, audio samples from the callback are appended to a buffer list, then concatenated into a numpy array.

P

Package
A Python directory containing an __init__.py file, making it importable as a module. Packages can be nested (sub-packages). AIVoiceStudio is a package with sub-packages: tts, gui, audio, etc.
Parameter vs. Argument
A parameter is a variable in a function definition; an argument is the value passed when calling the function. "The function accepts a path parameter" vs. "pass '/tmp' as an argument."
Parsing
Converting data from one format to a structured representation. AIVoiceStudio parses PDF (pypdf), DOCX (python-docx), TXT, EPUB, and DAISY documents into plain text for TTS processing.
Pathlib
Python's modern path handling module (3.4+). Path objects provide intuitive operators: parent, / for joining, .stem, .suffix, .exists(). Preferred over os.path for readability.
Piper
A fast, local neural TTS engine. AIVoiceStudio integrates Piper via sherpa-onnx for high-quality text-to-speech synthesis with multiple voices and languages.
Priority Queue
A data structure where elements are dequeued by priority rather than insertion order. Python's heapq module implements a min-heap. Used for task scheduling and job processing.
Property
A Python descriptor that manages attribute access with getter/setter/deleter methods. Defined with @property decorator. Provides computed attributes and encapsulation.
PyInstaller
A tool that bundles Python applications into standalone executables. Packages the Python interpreter, all dependencies, and native libraries into a distributable folder or single file.
PyPDF (pypdf)
A Python library for reading, splitting, and manipulating PDF files. AIVoiceStudio uses it to extract text from PDF documents for TTS processing.
Python-docx
A Python library for creating and reading Microsoft Word (.docx) files. AIVoiceStudio uses it to extract text from Word documents for TTS processing.
PythonExec
In AIVoiceStudio, the Python runtime subsystem for executing user-provided Python scripts within the application's environment, with sandboxed access to project files and settings.

Q

Queue
A FIFO (First In, First Out) data structure. queue.Queue is thread-safe for inter-thread communication. asyncio.Queue is for coroutines. Used for job processing in AIVoiceStudio.
QuickStart
A feature in AIVoiceStudio that provides one-click setup for downloading a default TTS model and creating a test project, allowing users to try the application immediately.

R

RAII (Resource Acquisition Is Initialization)
A C++ concept adopted in Python via context managers. Resources are acquired in __enter__ and released in __exit__, guaranteeing cleanup even if exceptions occur.
Raw String
A string prefixed with r that doesn't process escape sequences: r"C:\Users\test". Essential for regex patterns and Windows paths.
Refactoring
Restructuring code to improve readability, performance, or maintainability without changing external behavior. Common refactorings: extract method, rename, move, inline.
Reference Counting
Python's primary memory management mechanism. Each object tracks how many references point to it. When the count reaches zero, the object is immediately deallocated. Supplemental cyclic GC handles circular references.
Requests
A popular Python HTTP library. AIVoiceStudio uses it for downloading TTS models, checking API endpoints, and communicating with the OmniVoice server.
ReStructuredText (RST)
A markup language for documentation, used by Sphinx. Python's docstring conventions follow RST format. Not used in AIVoiceStudio's runtime, but common in Python ecosystem.
Runtime
The period during which a program is executing. In AIVoiceStudio, the runtime subsystem manages audio output devices, playback state, and session-scoped settings.

S

Sash Window
A wxPython window that can be resized by dragging a divider (sash). Used in AIVoiceStudio's main frame to create a resizable split between the project tree and content area.
Semaphore
A synchronization primitive that limits concurrent access to a resource. threading.Semaphore(n) allows up to n threads to proceed simultaneously. asyncio.Semaphore for async code.
sherpa-onnx
A C++/Python toolkit for running speech processing models (TTS, ASR, speaker identification) using ONNX Runtime. AIVoiceStudio's primary TTS engine for local, offline synthesis.
Sizer
wxPython's layout management system. Sizers automatically arrange child widgets within a container. Types: BoxSizer (linear), GridSizer (grid), FlexGridSizer, GridBagSizer.
Splitter Window
A wxPython widget that divides its area into two resizable panes separated by a movable sash. wx.SplitterWindow is used for master-detail layouts.
Static Method
A method defined with @staticmethod that doesn't receive self or cls. It's a regular function that lives inside a class's namespace for organizational purposes.
Streaming
Processing data incrementally as it arrives, rather than loading everything first. In TTS, streaming synthesis outputs audio chunks as they're generated, reducing latency. AIVoiceStudio's audio callback pattern implements streaming.
String Interpolation
Embedding expressions inside string literals. Python supports f-strings (f"{x}"), .format(), and % formatting. F-strings are preferred for readability and performance.
Subclass
A class that inherits from another class. Also called a child class or derived class. Can override parent methods and add new functionality.
Subprocess
Running external programs from Python via subprocess.run(), subprocess.Popen(). AIVoiceStudio uses subprocess to run FFmpeg for audio conversion.
Superclass
A class that is inherited from. Also called a parent class or base class. super() provides access to superclass methods for cooperative multiple inheritance.
Synthesis
Generating audio from text (TTS synthesis). In AIVoiceStudio, text is split into chunks, each chunk is sent to the TTS engine, and the resulting audio samples are concatenated into a complete audio file.
SysTray
System tray — the area near the clock in the taskbar. wxPython's TaskBarIcon allows applications to display an icon in the system tray with a context menu.

T

Tab Completion
IDE/REPL feature that suggests completions as you type. Powered by introspection (dir(), __doc__) and static analysis. IPython and modern IDEs provide rich tab completion.
Template Method Pattern
A design pattern where a base class defines the algorithm skeleton and subclasses override specific steps. In wxPython, EvtHandler.ProcessEvent is a template method.
Text Chunking
Breaking long text into smaller pieces for TTS processing. AIVoiceStudio's TextSplitter splits by sentence boundaries, respecting maximum character limits per chunk for the TTS engine.
Thread
A lightweight execution unit within a process. Python threads share memory but are limited by the GIL for CPU-bound work. Useful for I/O-bound tasks like downloads and TTS synthesis. threading.Thread is the API.
Thread Safety
Code that functions correctly when accessed by multiple threads simultaneously. In wxPython, GUI updates must use wx.CallAfter() from background threads. Locks and queues provide thread safety.
Throttle
Limiting the rate of operations. In AIVoiceStudio, UI updates during synthesis are throttled to avoid overwhelming the GUI event loop with too many status messages.
Timer
A wxPython widget that generates events at regular intervals: wx.Timer. Used for periodic checks, animations, and updating UI elements. Started with timer.Start(milliseconds).
Tkinter
Python's standard GUI toolkit, included with Python. Simpler than wxPython but less feature-rich. wxPython is preferred for professional cross-platform applications.
TTS (Text-to-Speech)
Technology that converts written text into spoken audio. AIVoiceStudio uses local TTS engines (Piper via sherpa-onnx) for offline, private speech synthesis.
Type Hint
Optional annotations in Python function signatures and variables: def greet(name: str) -> None:. Used by type checkers (mypy, pyright) and IDEs for static analysis, not enforced at runtime.
Type Checking
Verifying that code uses types correctly. Static type checking (mypy, pyright) analyzes code without running it. Dynamic type checking validates types at runtime.

U

Unpacking
Extracting values from iterables: a, b = [1, 2] (tuple unpacking), *rest = [1, 2, 3, 4] (star unpacking), func(**dict) (keyword unpacking).
UTC
Coordinated Universal Time — the primary time standard. Python's datetime.timezone.utc and datetime.utcnow() work with UTC. Essential for logging and timestamp accuracy.
UTF-8
A variable-width character encoding for Unicode. The dominant encoding for web and text files. Python 3 source files default to UTF-8. Handles all world scripts including CJK, Arabic, and emoji.
UUID (Universally Unique Identifier)
A 128-bit identifier designed to be unique across all computers and time. Python's uuid module generates v4 (random) UUIDs: uuid.uuid4(). Used for session IDs and unique project identifiers.

V

Virtual Environment
An isolated Python installation with its own packages, independent of the system Python. Created with python -m venv .venv. Prevents dependency conflicts between projects.
Void Return
Functions that don't explicitly return a value implicitly return None. Type-hinted as -> None. Common for side-effect functions (printing, modifying state, event handlers).
Viewport
The visible area of a scrollable window. In wxPython, GetClientSize() returns the viewport dimensions. AIVoiceStudio accounts for viewport size in layout calculations.
Voice Clone
AI technology that creates a synthetic voice matching a specific person's speech patterns from audio samples. AIVoiceStudio's clone feature uses user-recorded audio to generate a voice profile for TTS.
Voice Model
A trained neural network file that produces speech for a specific voice. Each model has parameters: language, speaker ID, quality level, and file size. Stored in ONNX format for cross-platform use.

W

WAV (Waveform Audio File Format)
An uncompressed audio format. The standard intermediate format for TTS output in AIVoiceStudio. Converted to compressed formats (MP3, OGG, FLAC) via FFmpeg for distribution.
Widget
A GUI element in wxPython: buttons, text fields, labels, panels, etc. All widgets inherit from wx.Window. Widgets are added to sizers for layout management.
Wildcard
In file dialogs, a pattern for filtering files by extension: "PDF files (*.pdf)|*.pdf|All files (*.*)|*.*". In Python, * in function parameters captures positional args as a tuple.
wxPython
A Python wrapper around the wxWidgets C++ GUI library. Provides native-look widgets on Windows, macOS, and Linux. AIVoiceStudio's GUI framework, chosen for its cross-platform capabilities and professional appearance.
wx.CallAfter()
A thread-safe method to schedule a function call on the main GUI thread. Essential for updating the UI from background threads in wxPython. Events are queued and processed in the next event loop iteration.
wx.Panel
A generic container widget that can hold other widgets. Panels provide a background for drawing and serve as parents for child controls. Used extensively in AIVoiceStudio's dialog layouts.

X

XML (Extensible Markup Language)
A markup language for structured data. Used in DAISY documents, DOCX files (OOXML), and many configuration formats. Python's xml.etree.ElementTree provides parsing.
XOR (Exclusive OR)
A bitwise operation returning true when inputs differ. In Python: ^ operator. Used for simple encryption, flag toggling, and hash computations.

Y

Yield
The keyword that makes a function a generator. yield value pauses the function and produces a value. The function resumes from where it left off when the next value is requested.
YAML (YAML Ain't Markup Language)
A human-readable data serialization format. Alternative to JSON with support for comments and complex types. Not used in AIVoiceStudio (which prefers JSON), but common in Python projects.

Z

Zip File
A compressed archive format. Python's zipfile module provides read/write access. AIVoiceStudio can import/export project data as zip archives.
Zero-Copy
Operations that don't create new data copies, improving performance. Python's memoryview and buffer protocol enable zero-copy slicing. NumPy array views are zero-copy.
Zone
In audio processing, a zone defines a region of audio for playback, editing, or effects. In AIVoiceStudio, synthesis zones map text segments to audio output regions.
