Chapter 62

Mocking & Test Doubles

Learning Objectives

  • Use unittest.mock for test isolation
  • Mock subprocess calls, file system, and network
  • See mocking patterns in the AIVS test suite

62.1 Mock Basics

from unittest import mock

# Mock a function return value
with mock.patch("ai_voice_studio.compute._has_nvidia_gpu", return_value=True):
    result = compute._has_nvidia_gpu()
    assert result is True

# Mock with side effects
mock_subprocess = mock.Mock()
mock_subprocess.run.return_value.returncode = 0
mock_subprocess.run.return_value.stdout = "NVIDIA RTX 3060\n"

# Patch multiple targets
with mock.patch("ai_voice_studio.compute.runtime.is_installed", return_value=True), \
     mock.patch.object(compute.subprocess, "run", return_value=FakeResult(0, "NVIDIA GPU\n")):
    det = compute.detect(force=True)

62.2 AIVS Mocking Patterns

# Pattern 1: Mock paths to use temp directory
patcher = mock.patch(
    "ai_voice_studio.paths.user_data_dir",
    return_value=temp_dir,
)
patcher.start()
self.addCleanup(patcher.stop)  # Auto-cleanup

# Pattern 2: Fake subprocess result
class _FakeResult:
    def __init__(self, returncode=0, stdout=""):
        self.returncode = returncode
        self.stdout = stdout

# Pattern 3: Mock GPU detection
def _patch(self, runtime_installed, nvidia):
    patches = [
        mock.patch("ai_voice_studio.compute.runtime.is_installed",
                   return_value=runtime_installed),
        mock.patch.object(compute.subprocess, "run",
            return_value=_FakeResult(0, "NVIDIA GPU\n") if nvidia
            else _FakeResult(1, "")),
    ]
    for p in patches:
        p.start()
        self.addCleanup(p.stop)

62.3 Key Takeaways

  • mock.patch() replaces functions/classes during tests
  • Always use addCleanup() or with to restore mocks
  • AIVS primarily mocks: paths, subprocess.run, nvidia-smi
  • tempfile.TemporaryDirectory + path mocking isolates file system tests
