Chapter 49

Model Downloader & Artifacts

Current implementation (2026.3.1). The downloader itself is unchanged, but it is no longer the only way an engine arrives. Engines whose catalog entry carries requires_package (the Voice Lab engines and both OmniVoice engines) are excluded from the Download/Remove list and are installed with pip into their own Python environment instead (Chapter 77). Those engines' models are fetched from Hugging Face by the engine itself on first synthesis. The shared artifacts (vocos-22khz for Matcha, the espeak-ng data for MMS) still arrive through this downloader.

Learning Objectives

  • Understand the download pipeline for voice models
  • Handle tar.bz2 extraction and file organization
  • See progress reporting and cancellation

49.1 Download Pipeline

class ModelDownloader:
    """Downloads and manages TTS voice model artifacts."""

    def download_variant(self, tts_id, lang, variant_id,
                         progress=None, cancel_event=None):
        """Download a voice variant (all its files)."""
        tts = catalog.find_tts(tts_id)
        variant = catalog.find_variant(tts, lang, variant_id)

        # Determine download URL from artifact name
        artifact = variant.get("artifact", "")
        url = self._build_url(tts_id, lang, artifact)

        # Download to temp location
        dest_dir = self.store.variant_dir(tts_id, lang, variant_id)
        os.makedirs(dest_dir, exist_ok=True)

        if artifact.endswith(".tar.bz2"):
            self._download_and_extract(url, dest_dir, progress, cancel_event)
        else:
            self._download_file(url, dest_dir, progress, cancel_event)

        # Mark as installed
        self.store.mark_installed(tts_id, lang, variant_id, dest_dir)

    def _download_and_extract(self, url, dest, progress, cancel):
        """Download tar.bz2 and extract to destination."""
        import tarfile, tempfile
        with tempfile.NamedTemporaryFile(suffix=".tar.bz2") as tmp:
            _download_file(url, tmp.name, progress, cancel)
            with tarfile.open(tmp.name, "r:bz2") as tar:
                tar.extractall(dest)

    def remove_variant(self, tts_id, lang, variant_id):
        """Remove a downloaded variant from disk."""
        dest = self.store.variant_dir(tts_id, lang, variant_id)
        shutil.rmtree(dest, ignore_errors=True)

49.3 Key Takeaways

  • Models are downloaded as tar.bz2 archives and extracted to the models directory
  • The ModelStore tracks what's installed via a JSON state file
  • Progress callbacks update the GUI gauge during download
  • Cancellation is checked between chunks via threading.Event
  • Shared artifacts (vocoders, espeak data) are stored once and referenced by multiple voices
