A.6 f-string Format Specifiers

SpecDescriptionExample
:.2f2 decimal placesf"{3.14:.2f}" → 3.14
:dDecimal integerf"{42:d}" → 42
:05dZero-paddedf"{42:05d}" → 00042
:,Thousands separatorf"{1000000:,}" → 1,000,000
:.1%Percentagef"{0.857:.1%}" → 85.7%
:>10Right-alignf"{'hi':>10}" → hi
:^10Centerf"{'hi':^10}" → hi
:=Debug expressionf"{x = }" → x = 42

A.7 Common Patterns

# Conditional assignment
x = value if condition else default

# Dictionary comprehension
{key: value for item in iterable}

# List comprehension with filter
[x for x in iterable if predicate(x)]

# Generator expression
sum(x for x in iterable)

# Ternary with collections
first = next((x for x in lst if pred(x)), None)

# Swap variables
a, b = b, a

# Unpack with ignore
first, *_, last = [1, 2, 3, 4, 5]
