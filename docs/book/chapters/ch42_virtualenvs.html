42.1 Why Virtual Environments?

Without venvs, installing wxPython for one project might overwrite a package needed by another. Virtual environments create isolated Python installations: 

# Create
python -m venv .venv

# Activate (Windows)
.venv\Scripts\activate

# Activate (macOS/Linux)
source .venv/bin/activate

# Install packages (only in this venv)
pip install wxPython numpy sherpa-onnx

# Deactivate
deactivate

42.2 AIVS PythonRuntime

# From python_runtime/__init__.py
class PythonRuntime:
    """Manages a separate Python venv for addons and optional engines."""

    def __init__(self, env_dir=None):
        self._env_dir = env_dir or os.path.join(
            paths.user_data_dir(), "addon_env"
        )

    def ensure_env(self) -> str:
        """Create the venv if it doesn't exist."""
        if self.is_created:
            return self._env_dir
        subprocess.run(
            [self.system_python, "-m", "venv", self._env_dir, "--clear"],
            check=True,
        )
        return self._env_dir

    def pip_install(self, packages, progress=None, cancel_event=None):
        """Install packages into the managed venv."""
        pip = self.ensure_pip()
        cmd = [pip, "install", "--no-warn-script-location"] + packages
        proc = subprocess.Popen(cmd, stdout=subprocess.PIPE, text=True)
        for line in proc.stdout:
            if progress:
                progress(line, 0, 0)
            if cancel_event and cancel_event.is_set():
                proc.terminate()
                return {"ok": False, "error": "Cancelled"}
        proc.wait()
        return {"ok": proc.returncode == 0}

    def run_in_env(self, script: str):
        """Run a Python script inside the managed venv."""
        return subprocess.run(
            [self.python_exe, "-c", script],
            capture_output=True, text=True,
        )

42.3 Key Takeaways

  • Virtual environments isolate project dependencies
  • AIVS has two venvs: the development venv (requirements.txt) and the managed addon venv
  • The PythonRuntime manages the addon venv for pip-installed engines (OmniVoice)
  • run_in_env() executes scripts inside the managed venv without affecting the main process
