59.1 What Is DAISY?

DAISY (Digital Accessible Information System) is a standard for accessible digital books. DAISY 2.02 books include synchronized audio and text, making them usable by blind and visually impaired readers with DAISY-capable players.

DAISY 2.02 File Structure

project/
├── ncc.html           # Navigation Center Combined (master TOC)
├── package.opf        # OPF content manifest
├── audio/
│   ├── Chapter_1.wav  # Audio files
│   └── Chapter_2.wav
├── smil/
│   ├── Chapter_1.smil # Audio-text sync files
│   └── Chapter_2.smil
└── Chapter_1.txt      # Text files (for audio+text mode)

59.2 Building the DAISY Book

# From documents/daisy_builder.py
def build_daisy_book(output_dir, project_name, segments,
                      audio_format="mp3", include_text=False,
                      language="en", publisher=""):
    """Build the complete DAISY 2.02 structure."""
    ready = [s for s in segments if s.get("status") == "done"]
    book_uid = str(uuid.uuid4())
    now_iso = datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")

    # 1. Generate NCC (Navigation Center Combined)
    _write_ncc(output_dir, project_name, ready, book_uid, now_iso,
               language, publisher, audio_format, include_text)

    # 2. Generate OPF (Open Packaging Format)
    _write_opf(output_dir, project_name, ready, book_uid, now_iso,
               language, publisher, audio_format, include_text)

    # 3. Generate SMIL files for each chapter
    _write_smil_files(output_dir, ready, audio_format, include_text)

59.3 Export as ZIP

def export_daisy_zip(project_dir, zip_path):
    """Package the DAISY book into a distributable ZIP."""
    with zipfile.ZipFile(zip_path, "w", zipfile.ZIP_DEFLATED) as zf:
        # Add NCC and OPF
        zf.write(os.path.join(project_dir, "ncc.html"), "ncc.html")
        zf.write(os.path.join(project_dir, "package.opf"), "package.opf")
        # Add audio and SMIL directories recursively
        for dirname in ["audio", "smil"]:
            dirpath = os.path.join(project_dir, dirname)
            for root, _, files in os.walk(dirpath):
                for file in files:
                    zf.write(os.path.join(root, file),
                             os.path.relpath(os.path.join(root, file), project_dir))

59.4 Key Takeaways

  • DAISY 2.02 is an accessible book format with audio-text synchronization
  • Three key files: ncc.html (TOC), package.opf (manifest), SMIL (sync)
  • AIVS supports both audio-only and audio+text DAISY modes
  • The builder is called automatically after recording completes
  • ZIP export packages everything into a single distributable file
