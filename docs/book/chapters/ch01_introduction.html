1.1 What Is Python?

Python is a high-level, interpreted, general-purpose programming language created by Guido van Rossum and first released in 1991. It emphasizes code readability with its use of significant indentation and English-like syntax. Today, Python is one of the most popular programming languages in the world, powering everything from web servers to artificial intelligence to desktop applications.

Why Python?

FeatureBenefit
InterpretedNo compilation step — run code immediately
Dynamically typedNo type declarations needed (but available via hints)
Extensive stdlibOver 200 modules in the standard library
Massive ecosystem400,000+ packages on PyPI
Cross-platformWindows, macOS, Linux with one codebase
AI/ML dominanceNumPy, PyTorch, TensorFlow all use Python
Desktop GUIswxPython, PyQt, Tkinter, Kivy

Python in AI Voice Studio

AI Voice Studio is a desktop application that converts text documents into spoken audio using neural text-to-speech (TTS) engines. It is built entirely in Python with wxPython for the GUI. This makes it a perfect learning vehicle because it touches every major area of Python development:

  • Core Python: File I/O, string processing, data structures, error handling
  • OOP: Classes, inheritance, polymorphism, encapsulation
  • Concurrency: Threading for background TTS synthesis
  • GUI: wxPython for native Windows interface
  • AI/ML: sherpa-onnx for neural speech synthesis
  • Networking: HTTP downloads of voice models
  • Packaging: PyInstaller and Inno Setup for distribution

1.2 Installing Python

System Requirements

  • Operating System: Windows 10/11 (64-bit), macOS 12+, or Ubuntu 20.04+
  • Python version: 3.11 or later (we use 3.13)
  • RAM: 4 GB minimum, 8 GB recommended
  • Disk: 2 GB free space (for TTS voice models)

Windows Installation

  1. Visit python.org/downloads
  2. Download the Windows installer (64-bit)
  3. Run the installer. Important: Check the box that says "Add python.exe to PATH" before clicking Install
  4. Verify the installation by opening a terminal and typing: 
    python --version
# Output: Python 3.13.0

1.9 The GitHub Copilot / AI-Assisted Development

Modern Python development often includes AI assistants. Throughout this book, we write code that is readable and well-documented — exactly the kind of code that AI assistants work best with. The AI Voice Studio project itself follows these principles:

  • Clear variable and function names (no single-letter variables except loop counters)
  • Docstrings on every public class and function
  • Type hints on function signatures
  • Constants instead of magic numbers

1.10 Key Takeaways

  • Python is interpreted — you write code and run it directly, no compilation step needed
  • Virtual environments are essential for isolating project dependencies
  • AI Voice Studio is a production-quality Python desktop app that demonstrates every major Python concept
  • The project has 53 Python source files across 13 subpackages, plus 12 test files
  • All core dependencies (wxPython, sherpa-onnx, numpy, requests, pypdf, python-docx) are installed from requirements.txt
