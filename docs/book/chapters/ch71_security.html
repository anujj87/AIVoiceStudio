71.1 Input Validation

# Filename sanitization prevents path traversal
def sanitize_filename(name: str, max_length: int = 80) -> str:
    name = re.sub(r'[<>:"/\\|?*]', '_', name)  # Remove dangerous chars
    name = re.sub(r'\s+', ' ', name).strip()
    if len(name) > max_length:
        name = name[:max_length].rstrip()
    return name

# JSON protocol validation
try:
    req = json.loads(line)
except json.JSONDecodeError:
    respond({"ok": False, "error": "Invalid request"})

71.4 Key Takeaways

  • Filename sanitization prevents path traversal attacks
  • Addons are sandboxed in their own directories with version checks
  • The HTTP server defaults to localhost-only binding
  • Bearer token auth protects the server when exposed on the network
  • JSON validation prevents injection through the IPC protocol
