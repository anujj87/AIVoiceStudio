Chapter 53

Model Management Panels

Current implementation (2026.3.1). Two additions to the panels described here: every panel with a Preview button now builds a Compute row from gui/compute_choice.make_compute_row (CPU, GPU when an NVIDIA GPU is detected, Auto when both exist), storing the choice under preview_compute.<category> and resolving it through provider_for_preview; and the available-voice list is enriched with each installed engine's built-in voices and any cloned voices, so they can be previewed and recorded everywhere. Package status is answered from the cached per-environment probes in venv_packages, never by blocking the UI thread. See Chapter 78.

Learning Objectives

  • Understand the Download and Available TTS panels
  • See cascading combo-box selection (TTS → language → variant)
  • Understand background download with progress

53.1 Cascading Selection Pattern

# Three cascading ComboBoxes narrow the selection:
# TTS Engine → Language → Variant → Voice

def populate_tts(combo, tts_list):
    combo.Clear()
    for tts in tts_list:
        combo.Append(tts["name"], tts["id"])

def populate_languages(combo, tts):
    combo.Clear()
    for lang in tts.get("languages", []):
        combo.Append(f"{lang['name']} ({lang['code']})", lang["code"])

def populate_variants(combo, tts, lang_code):
    combo.Clear()
    lang = catalog.find_language(tts, lang_code)
    if not lang: return
    for variant in lang.get("variants", []):
        combo.Append(variant["name"], variant["id"])

53.2 Background Download with Progress

class DownloadPanel(_ManagerPanel):
    def _on_download(self, _):
        self._cancel_event = threading.Event()
        self._thread = threading.Thread(
            target=self._download_job,
            daemon=True,
        )
        self._thread.start()

    def _download_job(self):
        def progress(name, done, total):
            wx.PostEvent(self, DownloadProgressEvent(name, done, total))
        try:
            self.downloader.download_variant(tts_id, lang, variant, progress=progress)
            wx.PostEvent(self, DownloadFinishedEvent(True, "Done!"))
        except DownloadCancelled:
            wx.PostEvent(self, DownloadFinishedEvent(False, "Cancelled"))

    def _on_progress(self, evt: DownloadProgressEvent):
        pct = int(evt.done * 100 / evt.total) if evt.total else 0
        self.gauge.SetValue(pct)
        self.progress_label.SetLabel(
            f"Downloading: {evt.done / 1048576:.1f} MB"
        )

53.3 Key Takeaways

  • Cascading ComboBoxes narrow selection: TTS → language → variant → voice
  • "Download all variants" option fetches every quality level of a language
  • Background threading keeps the GUI responsive during downloads
  • wx.PostEvent() sends progress updates from worker to GUI
  • Cancellation via threading.Event checked between download chunks
