3.1 if / elif / else

The if statement executes code based on a boolean condition:

# Basic if
has_gpu = True
if has_gpu:
    print("Using CUDA GPU")

# if / else
compute = "cpu"
if compute == "cuda":
    print("GPU mode")
else:
    print("CPU mode")

# if / elif / else (chain multiple conditions)
quality = "medium"
if quality == "low":
    size_mb = 50
elif quality == "medium":
    size_mb = 200
elif quality == "high":
    size_mb = 500
else:
    raise ValueError(f"Unknown quality: {quality}")

3.3 while Loops

while loops repeat as long as a condition is true:

countdown = 5
while countdown > 0:
    print(f"{countdown}...")
    countdown -= 1
print("Go!")

# Reading input until a sentinel value
while True:
    line = input("Enter command (or 'quit'): ")
    if line == "quit":
        break
    print(f"Executing: {line}")

# Polling pattern (used in AIVS server health checks)
import time
timeout = 30
deadline = time.monotonic() + timeout
while time.monotonic() < deadline:
    if health_check():
        print("Server is ready!")
        break
    time.sleep(1.0)

3.5 List Comprehensions

List comprehensions are a concise way to create lists. They combine a loop and an expression into a single line: 

# Traditional loop
squares = []
for x in range(10):
    squares.append(x ** 2)

# List comprehension (equivalent, more Pythonic)
squares = [x ** 2 for x in range(10)]
# [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# With filtering
even_squares = [x ** 2 for x in range(10) if x % 2 == 0]
# [0, 4, 16, 36, 64]

# Dict comprehension
engine_names = {t["id"]: t["name"] for t in tts_list}
# {"piper": "Piper TTS", "kokoro": "Kokoro TTS", ...}

# Set comprehension
languages = {v["language"] for v in installed_voices}
# {"en", "zh", "ja", "multi", ...}

# Generator expression (lazy — doesn't create list in memory)
total = sum(len(v["text"]) for v in segments)

# Matching with capture variables

3.9 Key Takeaways

  • Indentation defines blocks — use 4 spaces consistently
  • for iterates over any iterable; use enumerate() for index + value
  • while repeats while a condition is true
  • break exits the innermost loop; continue skips to next iteration
  • Loop else runs when the loop completes without break
  • List comprehensions are concise and often faster than equivalent loops
  • match/case (3.10+) is powerful for pattern matching on dicts and sequences
  • The AIVS catalog uses nested for loops to traverse TTS → language → variant → voice hierarchies
