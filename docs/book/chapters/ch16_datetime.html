Chapter 16

Date & Time

Learning Objectives

  • Use the datetime module for dates, times, and timezones
  • Format and parse dates with strftime and strptime
  • Use time.monotonic() for performance timing
  • See time handling in AIVS (DAISY timestamps, logging)

16.1 datetime Module

from datetime import datetime, date, time, timedelta, timezone

# Current date and time
now = datetime.now()
print(now)           # 2026-08-29 14:30:00.123456
print(now.date())     # 2026-08-29
print(now.time())     # 14:30:00.123456

# Create specific dates
birthday = date(2026, 8, 29)
release = datetime(2026, 12, 1, 10, 30, 0)

# UTC time
utc_now = datetime.now(timezone.utc)

# Time deltas
tomorrow = now + timedelta(days=1)
next_week = now + timedelta(weeks=1)
one_hour_later = now + timedelta(hours=1)
diff = release - now  # timedelta object
print(diff.days)      # Days until release

16.2 Formatting and Parsing

# strftime — format datetime as string
now = datetime(2026, 8, 29, 14, 30)
print(now.strftime("%Y-%m-%d %H:%M:%S"))  # "2026-08-29 14:30:00"
print(now.strftime("%B %d, %Y"))          # "August 29, 2026"
print(now.strftime("%c"))                  # Locale-specific

# strptime — parse string into datetime
dt = datetime.strptime("2026-08-29", "%Y-%m-%d")

# ISO 8601 format (used in AIVS DAISY builder)
iso = datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")
print(iso)  # "2026-08-29T19:30:00Z"

16.3 Time Performance Measurement

import time

# time.monotonic() — best for measuring elapsed time
start = time.monotonic()
# ... do work ...
elapsed = time.monotonic() - start
print(f"Elapsed: {elapsed:.3f}s")

# Used in AIVS server health check polling
def _wait_ready(self, timeout: float):
    """Poll health endpoint until server responds."""
    deadline = time.monotonic() + timeout
    while time.monotonic() < deadline:
        if self.health_check():
            return
        time.sleep(1.0)
    raise TimeoutError(f"Server not ready in {timeout}s")

# time.perf_counter() — highest resolution timer
start = time.perf_counter()
result = expensive_computation()
duration = time.perf_counter() - start

16.5 Key Takeaways

  • datetime.now() for current time; timezone.utc for UTC
  • strftime() formats; strptime() parses
  • time.monotonic() for measuring elapsed time (not affected by clock changes)
  • AIVS uses ISO 8601 timestamps for DAISY book metadata
