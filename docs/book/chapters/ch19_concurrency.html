Concurrency & Threading

Learning Objectives

  • Understand the GIL (Global Interpreter Lock) and its implications
  • Use threading for I/O-bound concurrency
  • Synchronize access with locks, events, and conditions
  • See threading patterns in AIVS (background TTS, downloads)

19.1 The GIL and When to Use Threads

Python's GIL (Global Interpreter Lock) means only one thread executes Python bytecode at a time. This makes threads unsuitable for CPU-bound work but excellent for I/O-bound tasks:

Task TypeSolutionAIVS Example
I/O-bound (network, disk)threadingDownloading models, file I/O
CPU-bound (computation)multiprocessingN/A (use subprocesses instead)
GUI + background workthreadingTTS synthesis + UI updates

19.4 Threading in AIVS

The Synthesis Worker Pattern

# From jobs/synthesizer.py — background TTS processing
class SynthesisWorker(threading.Thread):
    """Background thread that synthesizes audio segments."""

    def __init__(self, segments, voice_entry, params,
                 output_dir, on_segment_done, on_all_done,
                 on_error, cancel_event, pause_event, on_status):
        super().__init__(daemon=True)
        self._segments = segments
        self._voice_entry = voice_entry
        self._cancel = cancel_event
        self._pause = pause_event
        self._on_done = on_segment_done
        self._on_all_done = on_all_done
        self._on_error = on_error
        self._on_status = on_status
        self._output_dir = output_dir

    def run(self):
        """Main thread loop — runs in background thread."""
        try:
            engine = get_engine(self._voice_entry)
            for i, seg in enumerate(self._segments):
                # Check for cancellation
                if self._cancel.is_set():
                    break

                # Check for pause
                while self._pause.is_set():
                    if self._cancel.is_set():
                        break
                    time.sleep(0.1)

                # Synthesize
                self._on_status(f"Recording segment {i+1}...")
                audio = engine.synthesize(
                    seg.text,
                    speed=self._params["rate"],
                    pitch=self._params["pitch"],
                    volume=self._params["volume"],
                )

                # Save to disk immediately
                path = self._save_audio(seg, audio)

                # Notify GUI (thread-safe via wx.PostEvent)
                self._on_done(i, seg.title, path)

            self._on_all_done()
        except Exception as exc:
            self._on_error(str(exc))

    def cancel(self):
        self._cancel.set()

    def pause(self):
        self._pause.set()

    def resume(self):
        self._pause.clear()

EVT_SYNTH_STATUS = wx.PyEventBinder(_SYNTH_STATUS, 1)

class SynthStatusEvent(wx.PyCommandEvent):

        super().__init__(_SYNTH_STATUS)

# In the worker thread:
def _on_status(self, msg):
    wx.PostEvent(self, SynthStatusEvent(msg))

# In the GUI (main thread):
self.Bind(EVT_SYNTH_STATUS, self._handle_status)

def _handle_status(self, evt: SynthStatusEvent):
    self.status_label.SetLabel(evt.message)  # Safe — on main thread

19.5 Download Threading Pattern

# From gui/model_panels.py — background download
def _on_download(self, _):
    self._cancel_event = threading.Event()
    self._thread = threading.Thread(
        target=self._download_job,
        args=(tts_id, lang_code, variants),
        daemon=True,
    )
    self._thread.start()

def _download_job(self, tts_id, lang_code, variants):
    def progress(name, done, total):
        wx.PostEvent(self, DownloadProgressEvent(name, done, total))

    try:
        for variant_id in variants:
            self.downloader.download_variant(
                tts_id, lang_code, variant_id,
                progress=progress,
                cancel_event=self._cancel_event,
            )
        wx.PostEvent(self, DownloadFinishedEvent(True, "Done!"))
    except DownloadCancelled:
        wx.PostEvent(self, DownloadFinishedEvent(False, "Cancelled"))
    except Exception as exc:
        wx.PostEvent(self, DownloadFinishedEvent(False, str(exc)))

19.6 Key Takeaways

  • The GIL limits true parallelism in threads — use threads for I/O, not CPU work
  • threading.Thread creates background threads; always use daemon=True for non-critical threads
  • threading.Event is the primary mechanism for cancellation in AIVS
  • wx.PostEvent() is the only safe way to update GUI from worker threads
  • The AIVS SynthesisWorker pattern: thread + cancel event + pause event + GUI events
