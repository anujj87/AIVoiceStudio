PyInstaller Packaging

Learning Objectives

  • Understand how PyInstaller bundles Python apps

64.1 What PyInstaller Does

PyInstaller analyzes Python imports and bundles everything — the interpreter, all dependencies, and data files — into a single executable or folder.

# Basic usage
pip install pyinstaller
pyinstaller --onefile main.py

# With spec file (what AIVS uses)
pyinstaller packaging/ai_voice_studio.spec --noconfirm

64.2 The AIVS Spec File

# packaging/ai_voice_studio.spec (simplified)
a = Analysis(
    ['main.py'],
    pathex=[],
    binaries=[],
    datas=[
        ('ai_voice_studio/tts/catalog.py', 'ai_voice_studio/tts'),
    ],
    hiddenimports=[
        'wx',
        'sherpa_onnx',
        'numpy',
        'pypdf',
        'docx',
    ],
    hookspath=[],
    runtime_hooks=[],
    excludes=[],
    noarchive=False,
)

pyz = PYZ(a.pure)

exe = EXE(
    pyz,
    a.scripts,
    a.binaries,
    a.datas,
    [],
    name='AI-Voice-Studio',
    debug=False,
    strip=False,
    upx=True,
    console=False,  # No console window
    icon='packaging/icon.ico',
)

64.3 Build Commands

# From packaging/build.ps1
# Build x64 distribution
.venv\Scripts\python -m PyInstaller packaging\ai_voice_studio.spec `
    --noconfirm `
    --distpath dist\AIVS-64 `
    --workpath build\pyinstaller-x64

# Output: dist/AIVS-64/AI-Voice-Studio/AI-Voice-Studio.exe

64.4 Key Takeaways

  • PyInstaller bundles everything into a single executable or folder
  • The .spec file configures hidden imports, data files, and build options
  • AIVS output is ~39 MB (compressed)
  • console=False hides the console window for the GUI app
  • The build is automated via packaging/build.ps1
