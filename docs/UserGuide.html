AI Voice Studio — User Guide

Developed by Anuj Sharma. This guide explains installation, the first recording, every Settings category, voice cloning, punctuation, the compute back-ends and how to solve common problems. The application is designed to be fully usable with a screen reader (NVDA, JAWS, Narrator).

Installation

  1. Run AI-Voice-Studio-Setup-x64.exe and follow the installer.
  2. Choose whether to install for all users or only for you.
  3. When asked, choose whether to create a desktop icon and whether to launch the application after setup.

Nothing else needs to be installed: the CPU runtime and the TTS download manager are part of the application. GPU support, FFmpeg and the voice-cloning engine are downloaded on demand into your user folder.

Making your first recording

  1. Open Settings (Ctrl+,). In the Download and remove category choose a TTS engine (Piper is a good start), a language and a variant, then press Download selected variant. Wait for the download to finish.
  2. Close Settings. Press Ctrl+Shift+N to create a new project.
  3. Type a project name, press Open document and choose a PDF, TXT, DOC/DOCX, HTML or Markdown file. Choose the punctuation mode.
  4. Press Next, choose how the document is split into audio files, then press Finish. The Recording window opens.
  5. Choose a voice (TTS → language → variant → voice), set rate, pitch and volume if needed, then press Start recording.
Every finished segment is saved to the project folder immediately. You can close the Recording window at any time and continue later — reopening the project resumes from the first unsaved segment.

The main window

The main window shows a welcome message, three action buttons (Create New Project, Record, Settings) and a Recent projects list. Select a project with the arrow keys and press Enter to open it, or press the Remove selected project button below the list. Right-click the list for the same actions as the Edit menu.

Project lifecycle (Edit menu)

ActionWhat it does
Resume RecordingOpens the selected project; recording continues from the first unsaved segment.
Restart Project…Deletes all recordings and settings, keeps only the project name, and opens the New Project window again so you can choose a document and options afresh.
Restart All RecordingDeletes every recorded audio file; every segment is recorded again from the beginning.
Start Selected Recording…Opens a picker with a sidebar that decides what the combo box lists:
  • Select an audio file (default) — the files already recorded in the project folder, so one of them is recorded again.
  • Select by file break — every file break of the project, recorded or not, so recording can start at any break.
A second pair of options decides how far recording goes: Only record selected file records just that file and stops, while Record all files from here records the chosen file and then every file after it to the end of the project. The chosen file is deleted first so it is recorded again. Recording itself still starts from the Start recording button of the Recording window.
Remove Project…Removes the project from the menu and deletes its folder from your hard disk. This cannot be undone.

The Recording window

When the window opens, the first control is a read-only Text to record box that announces what will be spoken. Tab to the Compute back-end combo box, then the TTS, language, variant and voice combo boxes, the rate/pitch/volume sliders, and the output format (WAV, MP3 or FLAC).

  • Start recording begins (or resumes) synthesis.
  • Pause stops after the current segment; Resume continues.
  • Stop stops after the current segment; finished files stay saved.
  • MP3 and FLAC need FFmpeg; the app offers to download it into your user folder the first time you choose those formats.

Settings (all categories)

Settings uses the same layout as the NVDA screen reader's Settings dialog: a list of categories on the left, the selected category's panel on the right, and OK / Cancel / Apply buttons. Move through the categories with the arrow keys (the panel changes as you move), switch with Ctrl+Tab, press Enter for OK and Ctrl+S to apply without closing.

General

Theme (System / Light / Dark), the folders where recorded audio files and downloaded voice models are saved (each with a Browse… button), and Developer Mode which enables heavy logging, addon management, and diagnostic tools. Existing files are not moved when you change the folders.

Download and remove

Pick a TTS engine, language and variant, then download or remove it. Downloads show a progress bar and can be cancelled.

Available TTS

Lists the voices you have downloaded or cloned, grouped by engine. The fourth combo box selects the voice; Preview selected voice plays a short sample through that voice.

Voice clone

See Voice cloning below.

Recording settings

Default speed, pitch and volume for new projects, plus a preview text box and a Preview button that hears the current defaults through a downloaded voice.

Punctuation

The default punctuation mode for new projects, with a voice cascade (TTS → variant → voice), an example box that shows exactly how text will be spoken, and a Preview button that hears the example through the chosen voice.

Audio file creation

How the document is split into audio files (for example one file per page, or per heading). Each mode shows a description.

Compute

Shows the current back-end and manages the optional GPU (CUDA) runtime: Download GPU runtime fetches about 1.8 GB into your user folder; Remove GPU runtime deletes it. Restart the application after installing or removing it.

Reset

Restores every setting to its default value. Downloaded voices are not deleted.

Downloading voices

Voices are downloaded from the official open-source releases (k2-fsa/sherpa-onnx and rhasspy/piper). You only download the voices you actually use. Engines available: Piper/VITS (many languages), Kokoro, Matcha and Kitten TTS. Each engine has several language packs and quality variants; the voice list comes from the variant you install.

Kokoro tip: the “Version 0.19 (English only)” variant contains exactly 11 English voices. For Hindi, French, Chinese, Japanese, Italian and Portuguese voices choose the Multilingual (53 voices — all languages) variant instead — it contains every language voice in one download. Selecting a voice that is not in the installed variant plays the first English voice, so always match the voice to the variant you downloaded.

Voice cloning

Some TTS engines can copy a voice from a short recording. AI Voice Studio uses Coqui XTTS v2 for this — the standard offline model that clones a voice from a 4–5 second sample and speaks 17 languages.

  1. In Settings → Voice clone, section 1, press Download cloning engine. This installs coqui-tts and PyTorch (about 2.5 GB) into your user folder. The XTTS model itself (about 2.1 GB) downloads automatically on the first use.
  2. In section 2, type a voice name, choose the language of the sample, and press Browse… to choose a WAV recording of the person's voice. Four to five seconds of one clear voice with no background noise gives the best result.
  3. Press Create voice. The voice appears in Available TTS and in the Recording window as “Cloned voice: name”.

The first recording or preview with a cloned voice downloads the XTTS model and then takes a few seconds per sentence; later sentences are much faster. Cloned voices can be removed from the Cloned voices list.

XTTS v2 is licensed under the Coqui Public Model Licence, which is non-commercial. It is used for personal, research and educational purposes.

Punctuation modes

Not every TTS voice can pronounce punctuation. The punctuation mode chosen when the project is created decides how the text is prepared before it is sent to the voice:

  • Default — text passes through unchanged.
  • None — sentence punctuation is removed.
  • Math — sentence punctuation is removed; math symbols such as +, =, <, > are kept and spoken.
  • All — every mark is spoken as a word: my name is "anujsharma". becomes my name is quote anujsharma quote dot; print('hello') becomes print left paren tic hello tic right paren.

The exact spoken text of every recorded segment is saved as processed_text.json in the project folder, next to the audio file it produced.

Compute back-ends (CPU / GPU)

  • CPU — always available, bundled with the app.
  • GPU (CUDA) — needs the optional runtime downloaded from Settings → Compute. After a restart, the GPU back-end appears in the Recording window (Auto / GPU (CUDA) / CPU). An NVIDIA driver is the only requirement; no CUDA toolkit is needed.

Developer Mode

Enable Developer Mode in Settings → General → Enable Developer Mode to unlock advanced features:

  • Heavy logging — detailed diagnostic logs are written to %APPDATA%\AIVoiceStudio\logs\ with multiple subsystem files (gui.log, tts.log, engine.log, recording.log, addons.log, download.log) plus a crash log for unhandled exceptions.
  • Addon management — install, enable, disable and remove third-party addons from the Developer settings panel.
  • Python environment — manage the addon virtualenv, install pip packages, list installed packages.
  • Diagnostics — open the log folder, view system information, and access diagnostic tools.
Developer Mode requires restarting the application for heavy logging to take full effect. Addons are discovered on startup or when toggling Developer Mode.

Addon System

AI Voice Studio supports a plugin architecture inspired by the NVDA screen reader. Addons let you add new TTS engines, voices, and capabilities.

Installing an Addon

  1. Enable Developer Mode in Settings → General.
  2. Open Settings → Developer.
  3. Press Install addon from ZIP... and choose your addon archive.
  4. Restart the application to load the addon.

Managing Addons

In the Developer settings panel you can Enable, Disable or Remove installed addons. The addon list shows each addon's name, version, and status.

See the Addon Development Guide (Help menu) for full details on creating your own addons, adding TTS engines, and managing pip dependencies.

Troubleshooting

The recording produced an empty (silent) WAV file

This used to happen when the raw float samples were cast straight to int16. The engine now converts samples correctly. If you still hear silence, make sure the selected voice was downloaded completely (re-download it from Settings) and try the CPU back-end.

Recording fails with “Could not load the TTS model… graph.h:1997”

This error came from two different ONNX Runtime copies fighting inside one process. The app now ships exactly one ONNX Runtime. If you still see it, close the application, open Settings → Compute, remove and re-download the GPU runtime if you use it, and restart the app.

The GPU (CUDA) option does not appear

Download the GPU runtime in Settings → Compute and restart the application. The option only appears when the runtime is installed and an NVIDIA GPU is detected.

My cloned voice cannot be used

The cloning engine must be downloaded (Settings → Voice clone, section 1). The first use downloads the XTTS model (about 2.1 GB) automatically; on a slow connection this can take a while — the status text reports progress.

MP3 / FLAC output asks for FFmpeg every time

Accept the download prompt once; FFmpeg is saved to your user folder (%APPDATA%\AIVoiceStudio\ffmpeg) and reused afterwards.

Keyboard shortcuts do nothing while a dialog is open

Menu shortcuts (Ctrl+Shift+N and similar) work from the main window. While a modal dialog such as Settings or the Recording window is open, they are intentionally inactive; close the dialog first.

Where are my files?

  • Recorded audio and processed_text.json: the project folder.
  • Downloaded voices and clones: the model folder (Settings → General).
  • Optional runtimes and FFmpeg: %APPDATA%\AIVoiceStudio.
