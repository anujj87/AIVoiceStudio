AI Voice Studio

Developed by Anuj Sharma — version 0.1.0 — licence: GPL-3.0.

AI Voice Studio converts documents (PDF, TXT, DOC/DOCX, HTML, Markdown and clipboard text) into spoken audio files using free, offline neural voices. It is built with wxPython and sherpa-onnx, and it is designed to work well with screen readers such as NVDA, JAWS and Narrator.

Features at a glance

  • Offline text to speech — Piper, VITS, Kokoro, Matcha and Kitten voices, downloaded once from Settings and reused by all projects.
  • Voice cloning — clone a voice from a 4–5 second WAV sample with Coqui XTTS v2, in 17 languages (optional ~2.5 GB engine download).
  • Punctuation control — four modes, including “All”, which speaks every punctuation mark as a word (quote, dot, left paren, tic…) for voices that cannot pronounce punctuation.
  • Project-based recording — each document becomes a project; every segment is saved to disk immediately as WAV, MP3 or FLAC, and recording resumes where it stopped after a crash or close.
  • GPU acceleration — optional CUDA runtime (about 1.8 GB) downloaded from Settings → Compute; only an NVIDIA driver is required.
  • Screen-reader friendly — labelled controls, NVDA-style settings dialog, keyboard shortcuts throughout.

Quick start

  1. Open Settings (Ctrl+,) and use the Download and remove category to install at least one voice (for example Piper, English US, medium).
  2. Create a New Project (Ctrl+Shift+N), choose a document and how it is split into audio files, and pick the punctuation mode.
  3. Press Start recording in the Recording window. Each finished segment is saved immediately.

Computing back-ends

The app offers Auto, GPU (CUDA) and CPU back-ends in the Recording window.

  • CPU is always available: the CPU ONNX Runtime ships with the application.
  • GPU (CUDA) needs the optional GPU runtime, downloaded from Settings → Compute (about 1.8 GB, includes CUDA 12 and cuDNN 9). It activates after the application restarts. Only an NVIDIA driver is needed — no CUDA toolkit installation.

Voice cloning (XTTS v2)

Some TTS engines can copy a voice from a short recording. AI Voice Studio uses Coqui XTTS v2 for this: give the voice a name, choose the language spoken in the sample, and provide a 4–5 second WAV recording of one clear voice. The cloned voice then appears in Available TTS and the Recording window and can speak any of the 17 supported languages.

The cloning engine (about 2.5 GB, coqui-tts + PyTorch) is downloaded into your user folder from Settings → Voice clone; the XTTS model itself (about 2.1 GB) downloads automatically on first use. The XTTS model is licensed under the Coqui Public Model Licence (non-commercial).

Punctuation modes

  • Default — the text is passed to the voice unchanged.
  • None — sentence punctuation is removed before recording.
  • Math — sentence punctuation is removed, math symbols are kept and spoken.
  • All — every punctuation mark is replaced by its spoken word, e.g. my name is "anujsharma". becomes my name is quote anujsharma quote dot, and print('hello') becomes print left paren tic hello tic right paren.

The mode is chosen per project in the New Project window; the default for new projects is set in Settings → Punctuation, where you can also preview any mode through a selected voice.

Project lifecycle

  • Resume recording — continue where the last recording stopped.
  • Restart project — delete all recordings and settings, keep only the project name, and recreate the project.
  • Restart all recording — delete all audio files and record every segment again from the beginning.
  • Restart selected recording — choose one recorded file (from the files actually on disk) and record it again.
  • Remove project — delete the project from the menu and from your hard disk.

Storage

  • Projects, recorded audio and processed_text.json (the exact spoken text of every segment) live in the project folder.
  • Downloaded voices and cloned voices live in the model folder (changeable in Settings → General).
  • Optional runtimes (GPU, cloning engine) live under %APPDATA%\AIVoiceStudio\runtime.
